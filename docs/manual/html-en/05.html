4 Locals and flow

Builds on: Chapter 3 (signatures, named inputs).

Questions this chapter answers

  • When is a local made, and how far is it visible?
  • How are if, loop and case written, and what must they keep about the stack?
  • What is the short way to write a loop over an array?

4.1 Locals

In a body, to NAME puts the top value into that name. The first time a name is used, a local of the value’s type is made; there is no separate line that declares it.

04-locals.pnx

use io
word describe (a int, b int, c int gives str)
  a b add c add to total
  total 3 div to mean
  a b max c max to top
  cat ("total ", total, ", mean ", mean, ", largest ", top)
end
3 9 6 describe io.println

Output

$ pnx 04-locals.pnx
total 18, mean 6, largest 9

A local is visible from where it is first stored to the end of the branch, loop or block around it. A name first made inside a branch cannot be read outside it: coming by the other branch, it would hold no value.

04-scope.pnx

use io
word f (n int gives int)
  n 0 gt if n 2 mul to doubled end
  doubled
end

Refused

$ pnx 04-scope.pnx
04-scope.pnx:4:3: this name is not declared before this place

Inside a word, a global is stored with global. in front, as in to global.total; it is read by its name alone.

04-store-global.pnx

use io
global total int
word add_to_total (n int) total n add to global.total end     rem global.total: the global
3 add_to_total
4 add_to_total
cat ("total ", total) io.println

Output

$ pnx 04-store-global.pnx
total 7

Common mistake: Storing into a global with to total inside a word

Inside a word, to NAME always stores into a local. When the name is a global it is refused, and the message names to global.total. The rule keeps a store meant to make a local from changing a global. Outside words (load code) no local is made, so to total stores into the global there.

04-store-global-bare.pnx

global total int
word add_to_total (n int) total n add to total end

Refused

$ pnx 04-store-global-bare.pnx
04-store-global-bare.pnx:2:42: this name is a global; inside a definition a global is written with to global.name

4.2 Branches

condition if … else … end looks at the bool on top and runs one side. Both branches shall leave the same stack; a branch that leaves with return does not need to match.

04-if.pnx

use io
word grade (score int gives str)
  score 90 ge if "A" return end
  score 80 ge if "B" return end
  score 70 ge if "C" else "F" end
end
95 grade io.println
82 grade io.println
40 grade io.println

Output

$ pnx 04-if.pnx
A
B
F

An if without else shall leave the stack as it was. Leaving out the else of an if that leaves a value is refused.

04-if-unequal.pnx

use io
word label (n int gives str) n 0 lt if "negative" end end

Refused

$ pnx 04-if-unequal.pnx
04-if-unequal.pnx:2:51: an if without else must leave the stack as it found it

4.3 Loops

loop … end repeats. Inside it, condition until leaves when the condition is true, condition while when it is false, and break without a condition. One turn shall leave the stack as it found it — so the values a loop makes are gathered in locals.

04-loop.pnx

use io
word collatz (n int gives int)              rem steps to reach 1
  0 to steps
  loop
    n 1 eq until
    n 2 mod 0 eq if n 2 div else n 3 mul 1 add end to n
    steps 1 add to steps
  end
  steps
end
cat ("27 takes ", 27 collatz, " steps") io.println

Output

$ pnx 04-loop.pnx
27 takes 111 steps

A named loop can be left all at once from an inner loop.

04-named-loop.pnx

use io
word is_prime (n int gives bool)
  n 2 lt if false return end
  2 to d
  loop
    d d mul n gt if true return end
    n d mod 0 eq if false return end
    d 1 add to d
  end
end
word first_pair (target int gives str)       rem the first a < b <= 20, both prime, with a + b = target
  2 to a
  0 to b
  loop (outer)
    a 1 add to b
    loop
      b 20 gt until
      a is_prime b is_prime and a b add target eq and until (outer)
      b 1 add to b
    end
    a 1 add to a
    a 20 gt if "none" return end
  end
  cat (a, " + ", b)
end
26 first_pair io.println

Output

$ pnx 04-named-loop.pnx
7 + 19

Q&A

Q. Can I give the number of loops to leave instead?

A. No. With a number, wrapping a loop in one more would quietly leave another loop. A name cannot do that.

4.4 Choosing

case compares an int or str with the values of its branches. Several values for one branch go in parentheses. What to do when nothing matches goes in otherwise; with no otherwise and no match, it is a fault.

04-case.pnx

use io
word day_kind (day str gives str)
  day case
    ("sat", "sun") of "weekend" end
    ("mon", "tue", "wed", "thu", "fri") of "weekday" end
    otherwise "not a day" end
  end
end
"sun" day_kind io.println
"wed" day_kind io.println
"xyz" day_kind io.println

Output

$ pnx 04-case.pnx
weekend
weekday
not a day

The values of the branches are literals or consts of this source. Constants of modules such as err.full or json.key cannot be case values; compare them with eq.

4.5 Stems and blocks

A loop over an array or a list is written with a stem and a combining word instead. The name of the array is the stem, and a do … end block after it, with a word such as each, count or fold, takes it. The block is expanded in place, so it can use the locals around it.

04-stems.pnx

use io
use str
array temps int 7
assign temps (12, 15, 9, 21, 18, 7, 14)
cat ("sum ", temps sum, ", above 13: ", temps do (t int gives bool) t 13 gt end count) io.println
cat ("max ", temps maximum or_else (e) 0 end, ", min ", temps minimum or_else (e) 0 end) io.println
temps do (t int, i int) cat ("day ", i, ": ", t) io.println end each_index
word spread (gives int) 0 temps do (acc int, t int gives int) acc t 10 sub abs add end fold end
cat ("distance from 10, added up: ", spread) io.println

Output

$ pnx 04-stems.pnx
sum 96, above 13: 4
max 21, min 7
day 0: 12
day 1: 15
day 2: 9
day 3: 21
day 4: 18
day 5: 7
day 6: 14
distance from 10, added up: 34

lo hi range is a stem too (hi is not included). fold takes a first value before the stem, and its block takes (the value so far, an element) and gives the new value.

Summary

  • to NAME makes a local; with a global’s name it stores into the global (standard 9.4).
  • A name made inside a branch is not visible outside it (9.4).
  • The two branches of if and the branches of case leave the same stack; one turn of a loop leaves the stack it found (10).
  • A named loop is left at once with until (NAME) (10.2).
  • Arrays and lists are walked with stems: each each_index count fold sum … (10.6).
