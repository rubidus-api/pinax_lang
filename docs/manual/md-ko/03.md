# 2 값과 스택

> **먼저 알아야 할 것**: 1장(코드의 차례, `pnx`).
>
> **이 장이 답하는 물음**
>
> - Pinax 에는 어떤 값이 있는가?
> - 스택은 어떻게 움직이고, 처리기는 그것을 언제 검사하는가?
> - 정수가 넘치면 무슨 일이 일어나는가?

## 2.1 스택에서 계산하기

`02-stack.pnx`

```pinax
use io
use str
2 3 add 4 mul str.to_str io.println          rem (2 + 3) * 4
2 3 4 mul add str.to_str io.println          rem 2 + 3 * 4
10 3 sub str.to_str io.println               rem the first value is on the left: 10 - 3
10 3 swap sub str.to_str io.println          rem swap turns it round: 3 - 10
```

*출력*

```text
$ pnx 02-stack.pnx
20
14
7
-7
```

`2 3 add 4 mul` 을 차례로 따라가 보자. `2` 와 `3` 이 올라가고, `add` 가 둘을 내려 `5` 를 올리고, `4` 가 올라가고, `mul` 이 둘을 내려 `20` 을 올린다. 괄호가 없어도 계산의 차례가 글의 차례 그대로다.

빼기와 나누기처럼 차례가 중요한 낱말은 **먼저 올린 값이 왼쪽**이다. `10 3 sub` 는 10−3 이다. `swap` 은 위의 두 값을 바꾼다. 스택을 고치는 낱말은 `dup` `drop` `swap` `over` `nip` 다섯뿐이다. 그 이상이 필요하면 값에 이름을 붙인다(4장).

## 2.2 값의 타입

`02-values.pnx`

```pinax
use io
use str
use fmt
42 str.to_str io.println
-7 str.to_str io.println
0xff str.to_str io.println                   rem 255
1_000_000 str.to_str io.println
'A' str.to_str io.println                    rem a character is its number
3 4 lt if "3 < 4 is true" else "false" end io.println
"a string" str.len str.to_str io.println
255 fmt.hex io.println
```

*출력*

```text
$ pnx 02-values.pnx
42
-7
255
1000000
65
3 < 4 is true
8
ff
```

이 책에서 주로 쓰는 타입은 넷이다.

- `int` — 64 비트 정수. 십진, 십육진( `0xff` ), 이진( `0b101` )으로 적고 밑줄로 자리를 가를 수 있다. 문자 `'A'` 도 그 문자의 번호인 `int` 다.
- `bool` — `true` 와 `false` . 비교 낱말( `lt` `eq` …)이 내고 `if` 가 받는다.
- `str` — 문자열. 5장에서 자세히 본다.
- `err` — 실패의 까닭. 8장에서 본다.

> **문답**
>
> **물음. `int` 와 `bool` 은 서로 바뀌는가?**
>
> 답. 아니다. `1` 은 참이 아니고, `true` 에 더할 수도 없다. 조건 자리에는 `bool` 만, 산술에는 `int` 만 온다.

## 2.3 처리기는 스택을 미리 안다

처리기는 적재할 때 몸의 모든 자리에서 스택에 몇 개의 값이 어떤 타입으로 있는지 안다. 그래서 다음 두 프로그램은 돌기 전에 거절된다.

`02-types-mixed.pnx`

```pinax
use io
"3" 4 add drop
```

*거절*

```text
$ pnx 02-types-mixed.pnx
02-types-mixed.pnx:2:7: this word takes two int values, or two of the same declared type
```

`02-stack-short.pnx`

```pinax
use io
use str
5 add str.to_str io.println
```

*거절*

```text
$ pnx 02-stack-short.pnx
02-stack-short.pnx:3:3: the stack does not hold enough values for this word
```

> **흔한 오해: 스택의 깊이는 돌면서 바뀌어도 된다**
>
> Forth 같은 언어에서는 값의 수가 실행에 따라 달라지는 낱말을 쓸 수 있다. Pinax 는 그러지 않는다. 모든 자리에서 스택의 깊이와 타입이 하나로 정해져야 한다. 그래서 `if` 의 두 갈래는 같은 스택을 남겨야 하고, 루프의 한 바퀴는 스택을 그대로 둬야 한다(4장).

## 2.4 넘침은 결함이다

`02-overflow.pnx`

```pinax
use io
use str
word double (n int gives int) n 2 mul end
4611686018427387903 double str.to_str io.println
4611686018427387904 double str.to_str io.println
```

*결함으로 멈춤*

```text
$ pnx 02-overflow.pnx
9223372036854775806
02-overflow.pnx:3: integer overflow
  n int = 4611686018427387904
```

`int` 의 범위를 넘는 결과는 조용히 감기지 않는다. 실행이 그 자리에서 멈추고 처리기가 **결함**을 알린다. `pnx` 는 결함이 난 줄과 그 낱말의 지역 변수를 보여 준다. 감기는 산술이 필요하면 `wrap_mul`, 끝에서 멈추는 산술은 `sat_mul`, 넘침을 실패로 받으려면 `chk_mul` 을 쓴다.

## 2.5 십진 소수

돈처럼 점 아래 자릿수가 정해진 수는 점을 찍어 쓴다: `4.20` 은 점 아래 두 자리의 십진 소수 `dec(2)` 다. 정수 420 으로 담기므로 더해도 정확하고, 어느 기계에서나 같다. 같은 `dec(N)` 과 더하고 빼며, `int` 를 곱하고 `int` 로 나눈다. `dec` 둘을 곱하면 자리를 모두 지킨다. `rescale` 은 자릿수를 정하고, 0 에서 먼 쪽으로 반올림한다.

`02-dec.pnx`

```pinax
use io
word demo ()
  4.20 to coffee                          rem dec(2): two digits after the point
  coffee 3 mul 1.15 add to bill           rem times an int, plus another dec(2)
  bill 0.10 mul to tip                    rem dec(2) times dec(2): dec(4), nothing lost
  cat ("bill ", bill, ", tip ", tip, ", rounded ", tip 2 rescale) io.println
  cat ("split in three: ", bill 3 div) io.println
end
demo
```

*출력*

```text
$ pnx 02-dec.pnx
bill 13.75, tip 1.3750, rounded 1.38
split in three: 4.58
```

`int` 로 나누면 정수처럼 0 쪽으로 자른다: `9.75 3 div` 는 `3.25` 지만 `10.00 3 div` 는 `3.33` 이고 1 센트가 남는다. 그것이 중요하면 `raw` 로 센트를 꺼내 직접 나눈다.

> **흔한 오해: 4.20 과 0.5 는 더할 수 있다**
>
> 둘은 `dec(2)` 와 `dec(1)`, 다른 타입이다. `0.50` 으로 쓰거나 하나를 `rescale` 한다.
>
> `02-dec-scales.pnx`
>
> ```pinax
> word demo () 4.20 0.5 add drop end            rem dec(2) and dec(1)
> ```
>
> *거절*
>
> ```text
> $ pnx 02-dec-scales.pnx
> 02-dec-scales.pnx:1:23: two dec values of different scales: rescale one first (d 2 rescale)
> ```

> **정리**
>
> - 점이 있는 수는 `dec(N)` 이다: 점 아래 N 자리, 정확한 셈, 반올림은 `rescale` (표준 7.5).
> - 먼저 올린 값이 왼쪽이다: `10 3 sub` 는 7 이다(표준 9.3).
> - 스택 낱말은 `dup` `drop` `swap` `over` `nip` 뿐이다(9.3).
> - 타입은 적재 때 검사된다. `int` 와 `bool` 은 섞이지 않는다(7.1, 7.2).
> - 정수 넘침과 0 으로 나눔은 결함이다. 다른 산술 낱말이 따로 있다(7.1, 15.1).
