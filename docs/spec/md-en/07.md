# 7 Types and values

(1) Every value has a type fixed at load. Values do not carry their type while running, and no word asks for a type while running. A program whose types do not match is refused at load.

(2) The types are:

| **Type** | **Values** |
|---|---|
| `int` | 64-bit two’s complement integers (7.1) |
| `dec(N)` | decimals with N digits after the point, N from 0 to 18 (7.5) |
| `bool` | `true`, `false` (7.2) |
| `str` | a view of bytes (7.3); only in locals, arguments and results |
| `str(N)` | stored text of up to N bytes (7.3); in globals, cells of arrays, fields of records |
| `err` | the error code of a failure (11.1) |
| declared type | a type made with `type NAME base`: the same representation as its base, a different type (7.4) |
| row | one row of a table of records (array, list, pool); the type is named after the table (8.8) |
| handle | a number that refers to an object the host gave; the host names the type (19.6) |
| block | a word value, written `word (signature)` (10.5) |
| `regex` | a regular expression program (16.7); visible only in a source that has `use rex` |
| `buffer` | a parameter type: it takes a buffer the script declared (8.7, 9.9, 19.3) |

(3) Globals, cells of arrays and fields of records start at zero: `int` 0, `bool` `false`, `str(N)` the empty text, a row “none” (8.8).

## 7.1 Integers

(1) The values of `int` are the integers from −263 to 263−1, the same on every processor.

(2) The arithmetic words `add` `sub` `mul` `div` `mod` `neg` `abs` stop with the fault `overflow` when the result is out of range (11.3). There are words that wrap (`wrap_add` …), that stop at the edge (`sat_add` …), and that report overflow as a failure (`chk_add` …) (15.1).

(3) `div` rounds toward zero, and the result of `mod` has the sign of the dividend (`a b div b mul a b mod add` is `a`). `floor_div` and `floor_mod` round down. Division by zero is the fault `div_zero`.

`07-int.pnx`

```pinax
use io
use str
9223372036854775807 str.to_str io.println          rem the largest int
7 2 div str.to_str io.println                       rem division rounds toward zero
-7 2 div str.to_str io.println
-7 2 mod str.to_str io.println                      rem the remainder has the sign of the dividend
-7 2 floor_div str.to_str io.println                rem floor_div rounds down
9223372036854775807 1 wrap_add str.to_str io.println    rem wrap_add wraps around
9223372036854775807 1 sat_add str.to_str io.println     rem sat_add stops at the edge
```

*Output*

```text
$ pnx 07-int.pnx
9223372036854775807
3
-3
-1
-4
-9223372036854775808
9223372036854775807
```

#### Faults

(4) An overflow ends the run on the spot. In the example below the code after the line that overflows does not run.

`07-int-overflow.pnx`

```pinax
use io
global big int
9223372036854775807 set big
"before" io.println
big 1 add set big
"never printed" io.println
```

*Fault*

```text
$ pnx 07-int-overflow.pnx
before
07-int-overflow.pnx:5: integer overflow
```

## 7.2 Booleans

(1) `bool` has two values, `true` and `false`. Comparison words (`eq` `lt` …) give them; `if`, `while`, `until` and the logical words (`and` `or` `not`) take them.

`07-bool.pnx`

```pinax
use io
use str
3 4 lt if "3 is less than 4" else "no" end io.println
true false or not if "never" else "true false or not is false" end io.println
```

*Output*

```text
$ pnx 07-bool.pnx
3 is less than 4
true false or not is false
```

#### Constraints

(2) `bool` and `int` do not convert into each other. An `int` cannot stand where a condition goes, nor a `bool` where arithmetic goes.

`07-bool-not-int.pnx`

```pinax
1 if 2 drop end
```

*Refused*

```text
$ pnx 07-bool-not-int.pnx
07-bool-not-int.pnx:1:3: a bool is expected here
```

`07-int-not-bool.pnx`

```pinax
true 1 add drop
```

*Refused*

```text
$ pnx 07-int-not-bool.pnx
07-int-not-bool.pnx:1:8: this word takes two int values, or two of the same declared type
```

## 7.3 Strings

(1) A **string** is a sequence of bytes. There is no rule that it be UTF-8: words that work on bytes read bytes, and words that work on characters (`str.char_count` and so on) read UTF-8.

(2) There are two string types.

- `str` is a **view** : the start and length of bytes that are somewhere (a literal, the text of a global, a buffer, the region). Making one copies no bytes. It lives only in locals, arguments, results and on the stack.
- `str(N)` is **stored text** . It takes N bytes of room and copies the bytes put into it. It is used only in globals, cells of arrays and lists, and fields of records. Reading it gives a `str` view of that room.

`07-str.pnx`

```pinax
use io
use str
global name str(8)                 rem stored text: up to 8 bytes, copied in
word show (s str) cat ("[", s, "] ", s str.len) io.println end
"Pinax" set name
name show
"hello, world" 7 str.skip show        rem a view: no byte is copied
```

*Output*

```text
$ pnx 07-str.pnx
[Pinax] 5
[world] 5
```

#### Constraints

(3) `str` for a global, an array or a field of a record is refused: the bytes a view points at may disappear before that place does.

`07-str-global.pnx`

```pinax
global name str
```

*Refused*

```text
$ pnx 07-str-global.pnx
07-str-global.pnx:2:1: stored text is str(N); a str view lives only in locals, arguments and results
```

#### Faults

(4) Putting text longer than N bytes into a `str(N)` place stops with the fault `range`. It is not cut.

`07-str-too-long.pnx`

```pinax
use io
global name str(4)
"four" set name
"more than four" set name
```

*Fault*

```text
$ pnx 07-str-too-long.pnx
07-str-too-long.pnx:4: index out of range
```

(5) A view of bytes made in the region cannot be used once the region is rewound past them; 12.3 states this rule.

## 7.4 Declared types

#### Syntax

```ebnf
type-decl = "type" NAME base ;
base      = "int" | "bool" | "str" | "dec" "(" INT ")" ;
```

(1) `type meters int` makes the **declared type** `meters`. Its values are represented like `int` and cost nothing more to run, but at load it is a different type. It keeps numbers of different units from being mixed.

(2) The name of the type written after a value of the base type makes a value of that type (`1500 meters`). The word `raw` turns a value of a declared type back into its base type.

(3) Two values of the same declared type can be added and subtracted with `add` and `sub`; the result has that type. Comparison words and `min` `max` also take two values of the same type. Other arithmetic is done after `raw`.

`07-type.pnx`

```pinax
use io
use str
type meters int
type seconds int
word pace (d meters, t seconds gives int) d raw t raw div end     rem raw: the plain int
1500 meters 300 meters add 300 seconds pace str.to_str io.println
```

*Output*

```text
$ pnx 07-type.pnx
6
```

(3a) A value of a declared type `D` over `int` multiplied by an `int` (`D int mul`, `int D mul`), divided by one or taken modulo one (`D int div`, `D int mod`) gives a `D`. `neg` and `abs` give a `D` too. Scaling a number up or down keeps its unit. The product and the quotient of two `D` values are not a `D`, so this rule does not cover them.

`07-type-scale.pnx`

```pinax
use io
use str
type cents int
word share (total cents, people int gives cents) total people div end
word with_tax (c cents gives cents) c 110 mul 100 div end
1000 cents 3 share with_tax raw str.to_str io.println
```

*Output*

```text
$ pnx 07-type-scale.pnx
366
```

#### Constraints

(4) A value of a declared type given where another type goes is refused. Below, the two arguments are swapped.

`07-type-mixed.pnx`

```pinax
type meters int
type seconds int
word pace (d meters, t seconds gives int) d raw t raw div end
300 seconds 1500 meters pace drop          rem the two arguments are swapped
```

*Refused*

```text
$ pnx 07-type-mixed.pnx
07-type-mixed.pnx:4:25: an argument has another type than the word's signature asks for
```

(5) Arithmetic words other than `add` and `sub` on two values of a declared type are refused. So is any arithmetic word outside (3a) on a declared type and an `int`.

`07-type-arith.pnx`

```pinax
type meters int
2 meters 3 meters mul drop
```

*Refused*

```text
$ pnx 07-type-arith.pnx
07-type-arith.pnx:2:19: a declared type is added to and subtracted from its own type, and multiplied, divided or taken modulo by an int; for other arithmetic take raw
```

## 7.5 Decimals

#### Syntax

```ebnf
dec-type = "dec" "(" INT ")" ;   (* 0 to 18 *)
DEC      = [ sign ] digits "." digits ;   (* no exponent: 6.4 *)
```

(1) A value of `dec(N)` is a decimal number with `N` digits after the point. It is held as an `int` scaled by 10N: `12.50` is a `dec(2)` held as 1250. Results are the same on every processor. The range is that of `int` divided by 10N.

(2) A number with a point and digits on both sides, without an exponent, is a `dec(N)` literal whose `N` is the count of digits after the point: `12.50` is `dec(2)`, `0.5` is `dec(1)`, `-0.05` is `dec(2)`.

(3) `dec(N)` is a number type over `int` as a declared type is (7.4): two values of the same `dec(N)` are added, subtracted, compared and given to `min` and `max`; a `dec(N)` is multiplied by an `int`, divided by one (rounded toward zero, as `div`) and taken modulo one; `neg` and `abs` keep it. In addition `dec(A) dec(B) mul` gives `dec(A+B)`, exact, when `A+B` is at most 18. `sum`, `minimum` and `maximum` (10.6) take stems of `dec(N)` and give one. `chk_add` `chk_sub` `chk_mul` `chk_div` take a `dec(N)` as `add` `sub` `mul` `div` do. An overflow is the fault `overflow`.

(4) `n dec(N)` makes the `int` `n` into `n` with `N` zeros after the point (`5 dec(2)` is `5.00`); `d raw` gives the scaled `int` (`12.50 raw` is 1250). `d M rescale` gives `d` as a `dec(M)`, `M` a constant from 0 to 18: more digits are exact; fewer are rounded half away from zero (`2.345` is `2.35`, `-2.345` is `-2.35`).

`07-dec.pnx`

```pinax
use io
use str
type price dec(2)
word demo ()
  12.50 to unit                           rem dec(2): two digits after the point
  unit 3 mul to three                     rem times an int: still dec(2)
  three 0.75 add to bill
  cat ("bill ", bill, ", a quarter ", bill 4 div) io.println
  0.08 to rate
  bill rate mul to tax                    rem dec(2) times dec(2) is dec(4), exact
  cat ("tax ", tax, " -> ", tax 2 rescale) io.println
  cat (5 dec(2), " ", bill raw, " ", 9.99 price raw) io.println
  "19.9" 2 str.to_dec or_else (e) 0.00 end to read
  cat (read, " ", read bill gt) io.println
end
demo
```

*Output*

```text
$ pnx 07-dec.pnx
bill 38.25, a quarter 9.56
tax 3.0600 -> 3.06
5.00 3825 9.99
19.90 false
```

`07-dec-round.pnx`

```pinax
use io
word show (d dec(3)) cat (d, " -> ", d 2 rescale, ", ", d 0 rescale) io.println end
word demo ()
  2.344 show  2.345 show  -2.345 show  0.500 show  -0.500 show
end
demo
```

*Output*

```text
$ pnx 07-dec-round.pnx
2.344 -> 2.34, 2
2.345 -> 2.35, 2
-2.345 -> -2.35, -2
0.500 -> 0.50, 1
-0.500 -> -0.50, -1
```

(5) `type price dec(2)` declares a type over `dec(2)`; `9.99 price` makes one and `raw` gives the `dec(2)`. `dec(N)` is the type of globals, fields (8 bytes), cells of arrays and lists, values of queues and parameters (9.9) as `int` is. `str.to_str` and `cat` write it with all its digits (16.1); `str.to_dec` reads one.

#### Constraints

(6) Two `dec` values of different scales are not added or compared; `rescale` one first. A `dec` is not divided by a `dec`.

`07-dec-scales.pnx`

```pinax
word total (gives dec(2)) 1.50 0.5 add end      rem dec(2) and dec(1)
```

*Refused*

```text
$ pnx 07-dec-scales.pnx
07-dec-scales.pnx:1:36: two dec values of different scales: rescale one first (d 2 rescale)
```

`07-dec-div.pnx`

```pinax
word share (gives dec(2)) 10.00 3.00 div end
```

*Refused*

```text
$ pnx 07-dec-div.pnx
07-dec-div.pnx:1:38: a dec is divided by an int, not by a dec; for a share, rescale first and divide by the int
```

#### Diagnostics

| **Condition** | **Message** |
|---|---|
| A value that is not a `bool` where a condition goes | `a bool is expected here` |
| The two values of an arithmetic word differ in type or are not `int` | `this word takes two int values, or two of the same declared type` |
| Arithmetic outside (3) and (3a) on a declared type | `a declared type is added to and subtracted from its own type, and multiplied, divided or taken modulo by an int; for other arithmetic take raw` |
| An argument of another type than the signature | `an argument has another type than the word's signature asks for` |
| `str` for a global and the like | `stored text is str(N); a str view lives only in locals, arguments and results` |
| `str` for a field of a record | `a field holds str(N); a str view lives only in locals, arguments and results` |
| Two `dec` of different scales | `two dec values of different scales: rescale one first (d 2 rescale)` |
| A `dec` divided by a `dec` | `a dec is divided by an int, not by a dec; for a share, rescale first and divide by the int` |
| `dec(A) dec(B) mul` beyond 18 digits | `dec(A) times dec(B) is dec(A+B), and A+B is at most 18; rescale one first` |
| A scale outside 0 to 18 | `dec(N) has 0 to 18 digits after the point` |
