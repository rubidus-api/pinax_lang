# 15 Core words

(1) A **core word** is written as a bare name, without `use`. The tables of this clause write signatures as in 9.2. `T` means “any one type”; it is a notation for built-in words only. The stack words (`dup` `drop` `swap` `over` `nip`) are in 9.3 and the combining words that take stems in 10.6.

## 15.1 Integers

(1) Arithmetic. #### Constraints

(5) Integer words take `int` only (or two values of the same declared type, 7.4).

`15-max-str.pnx`

```pinax
"a" "b" max drop
```

*Refused*

```text
$ pnx 15-max-str.pnx
15-max-str.pnx:1:9: this word takes two int values
```

#### Faults

(6) `neg` and `abs` overflow at −263.

## 15.2 Comparison and logic

(1)**Word****Signature****Meaning**`eq` `ne``(T, T gives bool)`equal, not equal: `int` `bool` `str`, declared types, rows, error codes`lt` `le` `gt` `ge``(T, T gives bool)``int` (as signed), `str` (in byte order), declared types`and` `or``(bool, bool gives bool)`logical and, or; both values are computed`not``(bool gives bool)`negation`select``(bool, T, T gives T)`the first value when true, the second when false; no branch

`15-compare.pnx`

```pinax
use io
word yes (b bool gives str) b if "true" else "false" end end
"abc" "abc" eq yes io.println              rem strings compare by their bytes
"abc" "abd" lt yes io.println
-1 1 u_lt yes io.println                   rem as unsigned, -1 is the largest
true false ne yes io.println
```

*Output*

```text
$ pnx 15-compare.pnx
true
true
false
true
```
