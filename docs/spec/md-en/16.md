# 16 Standard modules

(1) The standard modules come with the processor. They are opened with `use MODULE` and written `MODULE.WORD` (13.1). Words of standard modules cannot reach outside without the host — they use no files, clocks or environment.

(2) Words of standard modules make no new storage. Their results are one of:

- a view of the bytes they were given; nothing is copied;
- a view of new bytes written in the region (12.2);
- bytes appended to a buffer the caller gave. Such words end in `_into` or take a buffer, and fail with `err.full` when there is not enough room.

## 16.1 str — strings

(1) The module `str` works on strings as bytes. Byte positions count from 0. Only the words that work on characters (`chars` `char_count` `is_utf8`) read UTF-8. Changing case (`upper` `lower`) changes ASCII only.

(2) Where a separator or a part to look for is taken (`sep`, `part`), a `str` or a single character (`int`, 6.5) may be given.

### 16.1.1 Looking and cutting

(3) All results are views of the string given.

| **Word** | **Signature** | **Meaning** |
|---|---|---|
| `len` `is_empty` | `(str gives int)` `(str gives bool)` | the number of bytes; is it empty |
| `take` `skip` | `(s str, n int gives str)` | the first `n` bytes; what follows them; when short, what there is |
| `take_last` `skip_last` | `(s str, n int gives str)` | the last `n` bytes; what comes before them |
| `slice` | `(s str, start int, n int gives str)` | `n` bytes from `start`; out of range is the fault `range` |
| `trim` `trim_left` `trim_right` | `(str gives str)` | the view without white space (space, tab, CR, LF) at the ends |
| `cut` | `(s str, sep gives str, str)` | before and after the first `sep`; without `sep`, `s` and the empty text |
| `try_cut` | `(s str, sep gives str, str or fail)` | like `cut`, but `err.not_found` without `sep` |
| `span` | `(s str, class int gives str, str)` | the leading bytes of that class, and the rest |

(4) The classes of `span` are the constants `str.digit` `str.alpha` `str.alnum` `str.space` `str.upper_case` `str.lower_case` `str.hex_digit` `str.punct` (ASCII).

`16-str-views.pnx`

```pinax

  "slice 7 3" "hello, world" 7 3 str.slice show
  "key = value" " = " str.cut to (k, v)
  "cut, before" k show
  "cut, after" v show
  "a=b=c" '=' str.cut to (k2, v2)                    rem the separator may be a character
  "cut at a char" v2 show
  "2026-10-15" str.digit str.span to (year, rest)
  "span digits" year show
  "span rest" rest show
end
demo
```

### 16.1.3 Making new text

(6) The results are new bytes written in the region; when the region is used up it is the fault `full` (12.2). The words that read numbers can fail.

| **Word** | **Signature** | **Meaning** |
|---|---|---|
| `upper` `lower` | `(str gives str)` | ASCII case changed |
| `repeat` | `(s str, n int gives str)` | `n` copies joined; a negative `n` is the fault `range` |
| `replace` | `(s str, old str, new str gives str)` | every `old` replaced by `new` |
| `pad_left` `pad_right` | `(s str, width int gives str)` | filled with spaces to `width` bytes; as it is when longer; a `width` below 0 or from 232 up is the fault `range` |
| `to_str` | `(int gives str)` | decimal text; a `dec(N)` with its `N` digits after the point (7.5) |
| `to_dec` | `(s str, N gives dec(N) or fail)` | read a decimal: a sign, digits, and a point with at most `N` digits after it (`N` a constant); more digits, or anything else, `err.format` |
| `to_int` | `(str gives int or fail)` | read as decimal: one sign and digits only (no spaces); otherwise, or beyond 64 bits, `err.format` |
| `to_int_base` | `(s str, base int gives int or fail)` | read in base 2–36; another `base` is the fault `range` |

### 16.1.4 Stems and writing into buffers

(7) Words that make stems (10.6):

- `s sep str.split` — the pieces between `sep` s, empty ones included; `sep` is a `str` or one byte (a `u8` constant, usually a character literal), as for `cut` and `try_cut` ;
- `s str.words` — the pieces between white space, no empty ones;
- `s str.lines` — the lines, without their LF or CR LF;
- `s str.bytes` — the bytes ( `u8` );
- `s str.chars` — one view ( `str` ) for each UTF-8 character.

(8) Words that write into a buffer:

- `sep buf STEM str.join_into` — appends the pieces of the stem joined by `sep` ( `or fail` ). The stem goes last, since the word right after a stem shall take it;
- `s old new buf str.replace_into` — appends the text with replacements and gives their number ( `gives n int or fail` ).

`16-str-stems.pnx`

```pinax
"" io.println
text END

END

"hi" str.bytes do (b u8) b str.to_str io.print " " io.print end each
"" io.println
"가a!" str.chars do (c str) cat ("<", c, " ", c str.len, ">") io.print end each
"" io.println
buffer out 64

out contents io.println
out clear
word swap_dashes () "a-b-c" "-" "+" out str.replace_into or_else (e) 0 end to n  cat (out contents, " (", n, " replaced)") io.println end
swap_dashes
```

## 16.2 fmt — numbers as text

(1) `cat` puts an `int` in decimal (9.8). Other forms are made into a `str` by the words of the module `fmt`. There is no small language of formats (such as `%08x`). Results are written in the region.

| **Word** | **Signature** | **Meaning** |
|---|---|---|
| `hex` `bin` | `(n gives str)` | hexadecimal (lower case), binary; `n` an `int` or a narrow integer (7.6): a negative `int` as 64-bit two’s complement, a narrow integer as the bits of its width |
| `hex_pad` | `(n, width int gives str)` | hexadecimal filled with leading zeros to `width` digits; `n` as for `hex` |
| `zero_pad` | `(n, width int gives str)` | decimal filled with leading zeros to `width`; the sign takes a place; `n` an `int` or a narrow integer (a `u64` unsigned) |
| `append_hex` | `(n, buf or fail)` | appends the hexadecimal to a buffer; `n` as for `hex` |

Decimal is `str.to_str`; decimal appended to a buffer is `append_int` (15.3). A `width` of `hex_pad` or `zero_pad` below 0 or from 232 up is the fault `range`; when the region is used up it is the fault `full`.

## 16.4 encode — bytes as text

(1) The words of the module `encode` are all `(s str, buf or fail)`. They append the result to the buffer and fail with `err.full` when there is not enough room, or `err.format` when the input has the wrong form.

## 16.5 bytes — binary data

(1) The module `bytes` writes numbers and text into a buffer as fixed byte forms, and reads them from bytes. The writing words are `(value, buf or fail)` (`err.full` when there is not enough room; nothing is written). The reading words are `(s str gives value, rest str or fail)` (`err.format` when the bytes run short or have the wrong form).

(2)

| **Word** | **Bytes** |
|---|---|
| `put_u8` `put_u16` `put_u32` `put_u64`  
`put_i8` `put_i16` `put_i32` `put_i64` | a value of the type the name says (7.6; `put_i64` an `int`), least significant byte first |
| the same names with `_be` | most significant byte first |
| `get_u8` … `get_i64`, `get_u16_be` … | their pairs: a value of the type the name says (`get_i64` an `int`) |
| `put_varint` `get_varint` | LEB128: the value as an unsigned 64-bit number, 7 bits at a time (a negative takes 10 bytes) |
| `put_str` `get_str` | a length (varint), then the bytes |

### 16.5.1 Records

(3) `row buf bytes.pack` appends one row of a record (8.8) to a buffer, field by field in order (`or fail`). `s row bytes.unpack` reads the fields from bytes into the row and gives the rest (`gives str or fail`). `row bytes.packed_size` is the number of bytes `pack` would write.

(4) The bytes of a field: an integer width as that width (most significant byte first when the record has `big_endian`, least significant first otherwise), `int` as 8 bytes, `bool` as 1 byte, `varint` as LEB128, `str(N)` as a length (varint) and the bytes, a field holding a row as the number it holds (varint).

(5) When `pack` fails the buffer goes back to the length it had before the call. `unpack` writes into the row only when every field can be read; when it fails the row is unchanged.

`16-bytes-pack.pnx`

```pinax

use bytes
use encode
use str
record item
  id u16
  name str(8)
  delta varint
end
record wire
  big_endian
  id u16
  count u32
end
array items item 2
array wires wire 1
buffer out 64
buffer hex 128
word dump () out contents hex encode.hex_encode or_else (e) end  hex contents io.println  hex clear end
word demo (or fail)
  0 items idx to a
  513 u16 a to item.id  "pinax" a to item.name  -3 a to item.delta
  a out bytes.pack or_fail
  dump
  cat ("packed_size ", a bytes.packed_size, ", written ", out contents str.len) io.println
  1 items idx to b
  out contents b bytes.unpack or_fail to rest
  cat (b item.id, " ", b item.name, " ", b item.delta, ", rest ", rest str.len) io.println
  "\x01\x02\x05" b bytes.unpack or_else (e) cat ("short input: ", e err_text) io.println "" end drop
  cat ("the row is unchanged: ", b item.name) io.println
  out clear
  0 wires idx to w
  258 u16 w to wire.id  7 u32 w to wire.count
  w out bytes.pack or_fail
  dump
end
demo or_else (e) e err_text io.println end
```

## 16.6 ptn — small patterns

(1) The module `ptn` finds and replaces text with **pattern**s of the size of Lua’s. It has no alternation (`|`), no repetition of groups and no back references; `rex` (16.7) takes the larger grammar.

### 16.6.1 The text of a pattern

(2) A pattern is a sequence of the items below, matched byte by byte.

| **Item** | **Matches** |
|---|---|
| an ordinary character | that byte |
| `.` | any byte |
| `%a` `%d` `%l` `%u` `%s` `%w` `%x` `%p` `%c` | letters, digits, lower case, upper case, white space, letters or digits, hexadecimal digits, punctuation, control characters (ASCII); in upper case, everything else |
| `%` and a character that is not a letter or digit | that byte itself (`%.` `%%` `%(`) |
| `[…]` `[^…]` | a set and its complement, with `a-z` ranges and `%` classes inside; a `]` right after `[` or `[^` is a member |
| `*` `+` `-` `?` after an item | zero or more (longest), one or more (longest), zero or more (shortest), zero or one |
| `( … )` | a capture; up to nine |
| `^` first, `$` last | anchored at the start, at the end of the text |

`16-ptn-classes.pnx`


## 16.7 rex — regular expressions

(1) The module `rex` finds and replaces with **regular expression**s. Its matching never goes back, so the time it takes is bounded by the length of the text times the size of the pattern. Write patterns as raw strings (6.5): in an ordinary string `"\d"` is refused as an unknown escape, and `"\b"` becomes a backspace.

(2) In a source that has `use rex` the type name `regex` is visible. A `regex` value is a pattern program that cannot be changed once made. It is used only in locals, arguments and results.

### 16.7.1 The text of a pattern

(3)

| **Form** | **Meaning** |
|---|---|
| a character | its bytes; a multi-byte character, its byte sequence |
| `.` | one UTF-8 character; without `(?s)` not a line break |
| `[abc]` `[a-z]` `[^…]` | a set; ranges are ASCII; a complemented set takes one UTF-8 character |
| `\d` `\w` `\s` `\D` `\W` `\S` | digits, word characters, white space and their complements (ASCII) |
| `*` `+` `?` `{n}` `{n,}` `{n,m}` | repetition (longest); with `?` after it, shortest |
| `a\|b` | alternation; the left first |
| `( … )` `(?: … )` | a group that captures, one that does not |
| `^` `$` | the start and end of the text; with `(?m)`, of each line |
| `\b` `\B` | a word boundary and its complement (ASCII) |
| `\n` `\t` `\r` `\f` `\v` `\0` `\xNN` | that byte |
| `\` and any other character | that character (`\.` `\*` `\\`) |
| `\zs` `\ze` | the match is narrowed to start, end here; the whole pattern must still match |
| `(?i)` `(?m)` `(?s)` | at the very start of a pattern only: ignore case (ASCII), anchors per line, `.` also matches a line break |

There are no back references, lookaround, Unicode properties or named groups.

(4) A pattern that repeats a body able to match the empty text (such as `(a*)*`) may give other captures than Perl or Python.

### 16.7.2 Words

(5) `re` is a `regex` value. “The match” is the range narrowed by `\zs` and `\ze`.

| **Word** | **Signature** | **Meaning** |
|---|---|---|
| `rx` | `(pat gives regex)` | makes the program at load; `pat` is a literal or a `const` |
| `compile` | `(pat str gives regex or fail)` | makes it while running; a malformed pattern is `err.format`; the program lies in the region |
| `is_match` | `(s str, re gives bool)` | is there a match |
| `match` | `(s str, re gives str or fail)` | the first match; `err.not_found` when none |
| `cut_match` | `(s str, re gives str, str, str or fail)` | what is before the first match, the match, and what is after |
| `matches` | stem | the matches in order; the block takes the whole match and one `str` parameter per group |
| `split` | stem | the pieces between the matches |
| `with_match` | `(s str, re, block or fail)` | runs the block once with the first match; `err.not_found` when none |
| `replace` | `(s str, re, rep str gives str)` | new text with every match replaced; in `rep`, `\0`–`\9` are groups |
| `replace_into` | `(s str, re, rep str, buf gives int or fail)` | appends the replaced text to a buffer and gives the number of replacements |
| `replace_by` | `(s str, re, buf, block gives int or fail)` | appends to a buffer, each match replaced by the text the block gives |

(6) When `matches`, `split` and `replace` search again from the next place, they still see the whole text, so `^` and `\b` know the bytes before that place.

## 16.8 json — JSON

(1) The module `json` reads and writes JSON (RFC 8259) text in one direction, without building a tree: it reads one token at a time and writes straight into a buffer.

### 16.8.1 Reading

(2) `s json.next` reads the first token of `s` and gives `(kind int, value str, rest str)` (`or fail`). At the end it fails with `err.not_found`; on something that is not a token, with `err.format`. White space, commas and colons between tokens are passed over. The structure of the grammar — matching brackets, where commas go — is not checked.

(3) `kind` is one of the constants below. The `value` of a string is its text without the quotes; when it has escapes, they are decoded into text written in the region. The `value` of a number is its text as written.

| **Constant** | **Token** |
|---|---|
| `json.object` `json.object_end` | `{` `}` |
| `json.array` `json.array_end` | `[` `]` |
| `json.key` | a string followed by a colon |
| `json.string` | any other string |
| `json.number` | a number |
| `json.boolean` `json.null` | `true` `false`, `null` |

(4) `s json.skip` passes over one value (with everything inside, for an object or array) and gives the rest (`gives str or fail`).

`16-json-read.pnx`

```pinax

word kind_name (k int gives str)                    rem the kinds are constants of json
  k json.key eq if "key" return end
  k json.string eq if "string" return end
  k json.number eq if "number" return end
  k json.boolean eq if "boolean" return end
  k json.null eq if "null" return end
  k json.object eq k json.array eq or if "open" return end
  "close"
end
word tokens (s str)
  s to rest
  loop
    rest json.next or_else (e) break end to (kind, value, rest)
    cat (kind kind_name, " ", value) io.println
  end
end
text END
{"name": "kim", "tags": [1, -2.5e3, true, null], "note": "café"}
END
tokens
```

### 16.8.3 Path, validity and layout

(5a) Four more words read the text as a whole, with the strict grammar of RFC 8259 (the token reader above is lenient on purpose: it reads a stream). A text is valid when it is one value and white space; a nesting deeper than 64 is not valid here. A path names a value: names joined by dots, an index in brackets, and a name that holds a dot or a bracket as `["a.b"]` (`user.langs[1]`, `[0].id`); the empty path names the whole text. A name is compared with the key as it is after its escapes are decoded. The reading stops where it finds the value, so the words do not check the rest of the text.

| **Word** | **Signature** | **Meaning** |
|---|---|---|
| `valid` | `(s str gives bool)` | whether `s` is one JSON value, with only white space around it |
| `at` | `(path str, s str gives kind int, value str or fail)` | the value `path` names in `s`: its kind (the constants above, never `json.key`) and its text, as `json.next` gives it, except that an object or an array is given whole, as written, to be read again by `json.next` or `json.at`. `err.not_found` when there is no such value (a name missing, an index past the end, a name asked of an array or an index of an object); `err.format` when the path is malformed or the text is malformed where it was read |
| `minify` | `(s str, b buffer or fail)` | appends `s` without the white space between its tokens; `err.format` when `s` is not valid, `err.full` when it does not fit (the buffer is then as it was) |
| `pretty` | `(s str, indent int, b buffer or fail)` | appends `s` with each member and element on a line of its own, `indent` blanks (0 to 16; any other number is a fault) to a level, `": "` after a key; an empty object or array stays as it is. The failures are those of `minify` |

## 16.9 csv — CSV

(1) The module `csv` reads and writes CSV in the form of RFC 4180: fields are separated by commas; a field that holds a comma, a quote or a line break is quoted, and quotes inside it are doubled.

(2) `s csv.fields` is a stem (10.6) of the fields of one line. A quoted field is given without its quotes and with doubled quotes made single. An unclosed quote gives the rest of the text as the last field (a stem cannot report a failure).

(3) The writing words append to a buffer (`or fail`, `err.full` when there is not enough room). `s buf csv.put`, `n buf csv.put_int`, `d buf csv.put_dec` and `b buf csv.put_bool` append one field (with the comma it needs); `buf csv.end_line` ends the line. Booleans are written `true` and `false`.

(4) `row buf csv.pack` appends one row of a record as one line. `s row csv.unpack` reads one line into the fields in order and gives what follows the line. The row is written only when every field is right (`err.format`). A `dec(N)` field is read and written as in `json` (16.8).

`16-csv.pnx`

```pinax
use io
use csv
record user
  name str(8)
  id u16
  admin bool
end
list users user 4
buffer out 128
"a,\"b,c\",\"d\"\"e\",,f" csv.fields do (x str) cat ("[", x, "]") io.print end each
"" io.println
word demo (or fail)
  users add_row or_fail to u
  "lee, jr" u to user.name  7 u16 u to user.id  true u to user.admin
  u out csv.pack or_fail                               rem a line, quoted where needed
  "x" out csv.put or_fail  5 out csv.put_int or_fail  false out csv.put_bool or_fail  out csv.end_line or_fail
  out contents io.print
  users add_row or_fail to v
  "zed,5,true\nrest" v csv.unpack or_fail to rest
  cat (v user.name, " ", v user.id, " ", v user.admin, " [", rest, "]") io.println
  "zed,5,maybe" v csv.unpack or_else (e) cat ("bad bool: ", e err_text) io.println "" end drop
end
demo or_else (e) e err_text io.println end
```

## 16.10 sheet — a book of tables of rows and columns

(1) The module `sheet` keeps tables of rows and columns, called **sheets**, in a buffer (8.7) the program declares: the buffer holds a **book**. It is a library, not a type, and it works as an adapter does: the program opens the book, makes sheets in it, chooses one by name or by number, and every other word then works on that **current sheet**. Every word of `sheet` takes the buffer, written last, as a collection parameter (9.9) does. A cell holds nothing, an `int`, a `bool`, a `dec(N)`, a date (Unix seconds, UTC) or a `str`, whatever the program puts there. The kind of a cell is known only to the module: a value leaves a cell through the word of its type (`int`, `str`, …), so every word has a fixed signature and the stack never holds a value of no type. How the cells, the pools and the indexes lie in the buffer is not part of the interface.

(2) Rows, columns and sheets are counted from 0. A row is added at the end by `add_row` and a sheet holds at most the `rmax` rows `create` was given. The number of columns is fixed by `create`; `widen` changes it. A value put in a cell is copied. Equal values are kept once, in a pool the whole book shares: a number that does not fit a cell, and every text, go to the pool with a count of the cells that hold them (in any sheet), and a cell that is overwritten, cleared or cut off gives its value back. A pool that has no room is `err.full`; free text space that is scattered is gathered when a new text needs it (and by `compact`). `sheet` is for tables that are read and written by index and by what they hold. What is found by a name is kept in an index (8.10).

### 16.10.1 Books and sheets

(3) A word other than the ones of this group needs a current sheet: without one it is the fault `state`. The first sheet made in a book is the current one. A name is 1 to 255 bytes and is kept once in the book. A sheet number is the order in which it was made; the number of a dropped sheet is given again to the next sheet made.

| **Word** | **Signature** | **Meaning** |
|---|---|---|
| `open_book` | `(nmax int, b buffer or fail)` | formats the buffer as a book of at most `nmax` (1 to 256) sheets, with none made; `err.full` when the buffer is too small. The buffer then reads as full: nothing can be appended over a book |
| `create` `create_cols` | `(name str, rmax int, cols int, b buffer gives int or fail)` | makes a sheet of at most `rmax` rows and exactly `cols` columns and gives its number. `create_cols` stores the sheet column by column: a scan of one column is several times faster, reading a whole row is slower. `err.format` when the name is taken; `err.full` when there is no room or number left |
| `activate` `activate_n` | `(name str, b buffer or fail)` `(n int, b buffer or fail)` | makes the sheet of that name, or that number, the current one; `err.not_found` when there is none. A read-only book cannot change its current sheet |
| `current` `sheets` | `(b buffer gives int)` | the number of the current sheet (-1 when there is none); one more than the highest number in use |
| `sheet_name` | `(n int, b buffer gives str or fail)` | a view of the name of sheet `n`, good until the next write to the book; `err.not_found` for a number not in use |
| `find_sheet` | `(name str, b buffer gives int or fail)` | the number of the sheet of that name; `err.not_found` otherwise |
| `remove` | `(name str, b buffer or fail)` | removes a sheet with its indexes and gives back what its cells held. When it was the current sheet there is none afterwards |
| `rename` | `(n int, name str, b buffer or fail)` | gives sheet `n` another name; `err.format` when the name is taken |
| `copy_to` | `(row1 int, col1 int, n int, row2 int, col2 int, b buffer or fail)` | copies a cell of the current sheet into a cell of sheet `n`, sharing the value; `err.not_found` when there is no sheet `n` |

### 16.10.2 Making and growing

(4) The words of this group work on the current sheet.

| **Word** | **Signature** | **Meaning** |
|---|---|---|
| `rows` `cols` `rows_max` | `(b buffer gives int)` | the rows now, the columns, the most rows |
| `add_row` | `(b buffer gives int or fail)` | adds an empty row and gives its number; `err.full` at `rmax` |
| `truncate_rows` | `(n int, b buffer)` | keeps the first `n` rows and gives back what the others held; more than there are is the fault `range` |
| `widen` | `(cols int, b buffer or fail)` | makes the sheet again with `cols` columns, keeping the rows, the values and the indexes. More columns need room in the book (`err.full`); fewer columns only when the cut columns are all empty (`err.format`). The old room is left as a hole that `compact` closes |
| `clear` | `(b buffer)` | removes every row |
| `compact` | `(b buffer)` | gathers the free space of the texts and closes the holes between the sheets |

### 16.10.3 Cells

(5) Words that take a row and a column fault with `range` when the cell is outside the table. A buffer that is not a table is the same fault.

| **Word** | **Signature** | **Meaning** |
|---|---|---|
| `put_int` `put_bool` | `(v int, row int, col int, b buffer or fail)` `(v bool, row int, col int, b buffer or fail)` | puts a copy in the cell; `err.full` when a pool is full |
| `put_date` | `(secs int, row int, col int, b buffer or fail)` | puts a date, the Unix seconds `secs` (UTC), in the cell; a value that does not fit 60 bits (any date of the years 1 to 9999 does) is the fault `range` |
| `put_dec` | `(v dec(N), row int, col int, b buffer or fail)` | puts a decimal with its scale |
| `put_str` | `(s str, row int, col int, b buffer or fail)` | puts a copy of the text; a view of this table may be given |
| `clear_cell` | `(row int, col int, b buffer)` | makes the cell empty |
| `copy_cell` | `(row1 int, col1 int, row2 int, col2 int, b buffer)` | copies a cell to another, sharing the value |
| `int` `bool` | `(row int, col int, b buffer gives int or fail)` `(... gives bool or fail)` | the value; `err.format` when the cell holds another kind (a date too: it is read with `date`) |
| `date` | `(row int, col int, b buffer gives int or fail)` | the Unix seconds of a date cell; `err.format` when the cell holds another kind |
| `dec` | `(row int, col int, N int, b buffer gives dec(N) or fail)` | a decimal with the scale `N` (a constant 0 to 18); `err.format` when the cell holds another kind or scale |

| `kind` `is_empty` | `(row int, col int, b buffer gives int)` `(... gives bool)` | the kind (`sheet.k_empty` 0, `k_int` 1, `k_bool` 2, `k_dec` 3, `k_str` 4, `k_date` 5); is it empty |

### 16.10.4 Finding and choosing

(6) A search compares numbers as numbers and texts by what they say. It looks at one column going down, or at one row going across. A text that is in no cell is found to be so at once.

| **Word** | **Signature** | **Meaning** |
|---|---|---|
| `find_row_int` `find_row_str` | `(key int, col int, b buffer gives int or fail)` `(key str, col int, ...)` | the first row whose column `col` holds `key`; `err.not_found` otherwise. This is `MATCH` of a spreadsheet; a date cell is found by its seconds, as `where_int`, `narrow_int` and the index treat it, and `sum_*` too; the value is then read with `int`, `str`, `date`, … (there is no word that gives a value of no type, as `VLOOKUP` does) |
| `find_col_int` `find_col_str` | `(key int, row int, b buffer gives int or fail)` | the first column of row `row`, across |
| `find_row_from_int` `find_row_from_str` `find_col_from_int` `find_col_from_str` | `(key, line int, from int, b buffer gives int or fail)` | the same, starting at row or column `from` |

(7) A sheet keeps a **selection**: a list of rows, at first all of them. `where_*` starts again from all the rows and keeps those whose column holds a value in the relation `op` with `v` (`sheet.eq` `ne` `lt` `le` `gt` `ge`); `narrow_*` keeps, of the rows now selected, those that are. Cells of another kind, and empty ones, are never in the relation. Because each word works on the selection of the sheet, a line of them is a pipe. The selection is kept in the book, per sheet.

| **Word** | **Signature** | **Meaning** |
|---|---|---|
| `where_int` `narrow_int` | `(col int, op int, v int, b buffer)` | selects, or narrows, by a number |
| `where_str` `narrow_str` | `(col int, op int, v str, b buffer)` | selects, or narrows, by a text (byte order) |
| `select_all` | `(b buffer)` | selects every row |
| `sel_len` | `(b buffer gives int)` | how many rows are selected |
| `sel_row` | `(k int, b buffer gives int)` | the row number of the `k`-th selected row; out of range is the fault `range` |
| `order_by` `order_by_desc` | `(col int, b buffer or fail)` | puts the selected rows in order of column `col`, smallest (largest) first, stably; numbers (a date as its seconds), then texts, then the rest. Room for the numbers is taken from the free end of the buffer (`err.full`) |

(8) The totals look at the int and date cells only (a date counts as its seconds). `sum_*` is the fault `overflow` when the sum does not fit; `min_*` and `max_*` fail with `err.not_found` when there is no number.

| **Word** | **Signature** | **Meaning** |
|---|---|---|
| `sum_col` `min_col` `max_col` `count_col` | `(col int, b buffer gives int)` | over column `col`, all rows; `min` and `max` `or fail` |
| `sum_row` `min_row` `max_row` `count_row` | `(row int, b buffer gives int)` | over row `row`, all columns |
| `sum_sel` `min_sel` `max_sel` `count_sel` | `(col int, b buffer gives int)` | over column `col` of the selected rows |

### 16.10.5 Ordered indexes

(9) A column can have an **index**: an ordered structure over its numbers and texts (numbers first, then texts by bytes, ties by row), a B+tree of pages taken from the free end of the book. `index` builds it, writes to the column keep it in step, `unindex` frees its pages. With an index `find_row_*` (down the column), `where_*` with every relation but `ne`, and `order_by` with every row selected answer without scanning, in time that grows with the logarithm of the rows and the number of rows found; the answers are the same as without it, rows in row order. An index costs a write, and a book whose pages and sheets fill the buffer refuses a new one with `err.full`; a write that would need a page that is not there is `err.full` too and changes nothing. The index is a means, never a meaning: a program that does not use it works as before.

| **Word** | **Signature** | **Meaning** |
|---|---|---|
| `index` | `(col int, b buffer or fail)` | builds the index of column `col` of the current sheet (nothing when there is one); `err.full` when the book has no pages left |
| `unindex` | `(col int, b buffer)` | removes it |
| `indexed` | `(col int, b buffer gives bool)` | whether the column has one |

### 16.10.6 Files

(9a) CSV and xlsx files are read into the current sheet and written from it, without any power over files: the program reads the file into a `buffer` (`file.read_all_into`) and writes the buffer out (`file.write` of `contents`). These words take **two buffers**, the file first and the book last (`0 blob book sheet.load_csv`); the two are different buffers, and a name for the file may be a collection parameter (9.9) while the book is a buffer of its own. A word that takes the file may change the bytes of its buffer: it is a work area (a shared buffer is refused). A load adds rows after the last row of the current sheet and gives the number added; when it fails, the sheet is as it was. Rows beyond `rows_max` or columns beyond the sheet are `err.full`, a text that is not a CSV or a file that is not an xlsx is `err.format`. The `mode` is 0, 1 or 2 (any other is a fault).

| **Word** | **Signature** | **Meaning** |
|---|---|---|
| `load_csv` | `(mode int, f buffer, b buffer gives n int or fail)` | reads the text in `f`: lines end with LF or CRLF, fields with commas, a quoted field holds commas, line breaks and doubled quotes (it is unescaped in place), blank lines and a UTF-8 BOM are skipped. Mode 0: a field that is an integer in its canonical form (`-?(0\|[1-9][0-9]*)`, fitting an int) becomes an `int`; a canonical integer with 1 to 18 digits after the point, fitting, becomes a `dec` of that many digits (`1.50` is `dec(2)`); an empty field is an empty cell; any other, `007` and `-0` too, is text. Mode 2: as mode 0, and a field that is a date, `YYYY-MM-DD`, or with `T` or a blank and `hh:mm:ss` (and perhaps a `Z`), that exists, becomes a date cell (UTC; a date alone is midnight). Mode 1: all text |
| `load_xlsx` | `(mode int, n int, f buffer, b buffer gives rows int or fail)` | reads sheet `n` (0 first, in the order of the workbook; `err.not_found` when there is none) of the xlsx in `f`. Numbers follow the CSV rule (the digits after the point beyond 18 are rounded; an exponent is applied; a value that does not fit is text), shared, inline and formula-result strings are text (rich text is joined, phonetic runs dropped), `t="b"` is a `bool`, an error value (`#N/A`) is text, a formula gives its stored result. A cell whose number format is a date or time (built-in formats 14 to 22, 27 to 36, 45 to 47, 50 to 58, 71 to 81, or a custom format with `y`, `d`, `h`, `s` or `m` outside quotes and brackets, `[h]` and `[mm]` included) is, in mode 0, an `int` of Unix seconds (UTC, the 1900 or 1904 date system of the file, a time of day alone counted from midnight); in mode 1 it stays the serial number as a `dec`, in mode 2 it is a date cell with those seconds (the other cells as in mode 0). Rows and columns the file leaves out are empty cells |
| `save_csv` | `(dst buffer, b buffer gives n int or fail)` | replaces the contents of `dst` with the current sheet as CSV (up to its last used row and column; texts quoted when they hold a comma, a quote or a line break; `dec` with its digits; `bool` as `true` and `false`; a date as `YYYY-MM-DD`, with `Thh:mm:ss` when it is not midnight, and outside the years 0 to 9999 as its seconds) and gives the bytes; `err.full` when `dst` is too small (it is then empty) |
| `save_xlsx` | `(dst buffer, b buffer gives n int or fail)` | replaces the contents of `dst` with an xlsx of the current sheet (one sheet, named like it, at most 31 characters without `[]:*?/\`; texts as inline strings; numbers, `dec` and `bool` as such; a date as an Excel date, the serial number of the 1900 system with the format `yyyy-mm-dd hh:mm:ss` (a styles part is written only for a sheet that has one), read back by mode 2 with the same seconds; before 1900-03-01 or after 9999-12-31 the format cannot say it and the seconds are written as a plain number). The ZIP is stored, not compressed |

(9b) **work area**: nothing is allocated (clause 12). `load_xlsx` uses the spare capacity of the buffer that holds the file after its last byte, about 130 KB (a window for the inflate, the scanner’s buffers) plus the decoded shared strings (4 bytes for each and their text). The buffer is declared larger than the file; when the room does not suffice the load is `err.full`. A part of the file is read through the central directory of the ZIP: ZIP64, encrypted parts and methods other than stored and deflate are `err.format`, as is a part larger than 256 MiB when inflated. Every byte inflated is charged to the instruction budget.

## 16.11 toml — TOML

(1) The module `toml` reads TOML text of version 1, a file of settings, without building a tree. A value is given as the bytes it has in the text, and a string without its quotes; a string with escapes, or of several lines with a backslash at the end of a line, is decoded into text written in the region (12.2). Nothing is converted: a number is given as written (`5_000`, `0xff`), to be read by the program with the word of the type it wants. The module can also change a file (below), keeping every byte it does not change.

(2) `kind` is one of the constants below.

| **Constant** | **Value** |
|---|---|
| `toml.table` | a header `[a.b]`, or a table a path names: no value |
| `toml.tables` | a header `[[a.b]]` of an array of tables: no value |
| `toml.string` | a string of any of the four kinds |
| `toml.int` `toml.float` | a number as written; `inf` and `nan` are floats |
| `toml.bool` | `true` or `false` |
| `toml.datetime` | a date, a time or both, as written (`1979-05-27T07:32:00Z`) |
| `toml.array` `toml.inline` | an array or an inline table whole, as written, to be read again by `toml.at` |

### 16.11.1 Reading

(3) `s toml.next` reads the first statement of `s` and gives `(kind int, key str, value str, rest str)` (`or fail`): a header (`kind` `toml.table` or `toml.tables`, `key` the name between the brackets as written, `value` empty) or a pair (`key` as written, dots and quotes included, `value` as above). Blank lines and comments are passed over. At the end it fails with `err.not_found`; a statement that is not TOML is `err.format`. The program keeps the header it is under; every `key` is relative to it.

(4) `path s toml.at` gives `(kind int, value str)` (`or fail`): the value `path` names, in the way a reader of the file would see it. A path is names joined by dots (a quoted name, `"a.b"` or `'a.b'`, may hold dots) and indexes in brackets: `server.ports[1]`, `user[0].name`, `a."b c".d`. Keys given with dots (`a.b.c = 1`), tables made by a header, inline tables and arrays are all followed, and an index chooses an element of an array of values or of tables (the order of the `[[...]]` headers; those below an element belong to it). A path that names a table gives `toml.table` and no value. `err.not_found` when there is none; `err.format` when the path is malformed or the text is malformed where it was read.

(5) `s toml.valid` gives whether every statement of `s` is well formed. The check is of the syntax of each statement: a key given twice, a table defined twice and the range of a number or the existence of a date are not checked by it.

(6) `s toml.check` (`or fail`) checks the rules of the whole document as well: a key is defined once, a table once (a table made by a header may be named again only as the parent of one already made), a table made by dotted keys is not opened again by a header, an inline table and an array are closed (nothing is added to them later), and an array of tables is not also a table. Every integer must fit 64 bits signed, every float must be finite, and a date or time must exist (the month and the day of that year, hours to 23, minutes to 59, seconds to 60; seconds are required, as in TOML 1). `err.format` when a rule is broken or a statement is malformed; `err.full` when the region has no room for the table the check keeps (at most one node for each byte of `s`; it is given back when the word ends), never “valid”. A name written with escapes is the same key as the same name written bare, and a part with escapes longer than 256 bytes is `err.full`.

(7) `path s value kind b toml.set` (`or fail`) appends to `b` the text `s` with the value of `path` set: the value of a key that is there is replaced (an element of an array too), the comments and the layout stay. A key that is not there is added at the end of the statements of its table (the root table: before the first header), dotted from there when the path goes through tables that are not yet there (`server.tls.on = 1`); a table that exists only through the headers of tables below it gets a header of its own at the end of the text. `kind` is `toml.string` (`value` is the text, written quoted and escaped; it must be UTF-8), `toml.int`, `toml.float`, `toml.bool` or `toml.datetime` (`value` is the text of one, as the language writes it, and a number out of range or a date that does not exist is refused), or `toml.array` (`value` is an array on one line). Another kind, a table as a path, a path under a value, and an index beyond an array of tables are not written: `err.format`, except an index of an array of tables that is not there, which is `err.not_found`. The text `s` and the result must keep the rules of `toml.check`, else `err.format`; `err.full` when the buffer has no room, and the buffer is then as it was.

(8) `path s b toml.remove` (`or fail`) appends to `b` the text `s` without the statement of the key `path` names, from the start of its line to the end of it (a comment on that line goes with it). `err.not_found` when there is none; `err.format` for a table, for an element of an array or of an inline table (they are not statements of their own), or when the text is malformed; `err.full` as for `toml.set`.

| **Word** | **Signature** | **Meaning** |
|---|---|---|
| `valid` | `(s str gives bool)` | whether every statement of `s` is well formed |
| `check` | `(s str gives or fail)` | the rules of the whole document; `err.format`, `err.full` |
| `at` | `(path str, s str gives kind int, value str or fail)` | the value `path` names in `s`; `err.not_found`, `err.format` |
| `next` | `(s str gives kind int, key str, value str, rest str or fail)` | the first statement of `s` and what is left after it; `err.not_found` at the end, `err.format` |
| `set` | `(path str, s str, value str, kind int, b buffer or fail)` | appends `s` with the value of `path` set; the rules above |
| `remove` | `(path str, s str, b buffer or fail)` | appends `s` without the statement of the key `path` |

## 16.12 md — Markdown

(1) The module `md` reads Markdown, a text for people, and writes it as HTML. It is a subset of CommonMark with the tables and the strikethrough of GFM, made for the notes, the READMEs and the pages a script meets; it is not every corner of the specification. Raw HTML in the text is never passed on: `<` is written as `&lt;`. A link or an image whose address has a scheme other than `http`, `https`, `mailto`, `tel` and `ftp` is written as its text only. So the HTML is safe to put in a page whatever the Markdown was.

(2) What is read. Blocks: ATX headings (`#` to `######`) and setext headings, paragraphs, thematic breaks, block quotes, lists (bullets `-` `+` `*`, numbers `1.` `1)`, nested, tight or loose), fenced code (three or more backticks or tildes, the first word of the info string becoming `class="language-..."` when it is letters, digits and `- _ + # .`), indented code, and tables (a row, a row of dashes with colons for the alignment, rows). Inline: emphasis `*a*` `_a_`, strong `**a**` `__a__`, strikethrough `~~a~~`, code spans, links `[text](address "title")`, images `![alt](address)`, autolinks `<https://...>` and `<a@b.c>`, backslash escapes, character references (`&amp;` `&#65;`), a hard break (two blanks or a backslash at the end of a line). Not read: link reference definitions, raw HTML, a setext heading after a list, and the finer rules of CommonMark for emphasis next to punctuation; these give text or a plain paragraph, never a failure. A nesting of containers or of emphasis deeper than 12 is written as text. The search for the closing mark of a link, an emphasis or a code span is paid from a budget of sixteen bytes for each byte of the text; when it is spent, the marks left are text, so a text that is all unclosed marks is read in a time that grows with its size.

### 16.12.1 Writing HTML

(3) `s b md.html` appends the HTML of the Markdown text `s` to the buffer `b`, `s b md.inline` that of one line or paragraph, with no block around it. They fail with `err.full` when there is not enough room (the buffer is then as it was). The room is needed for the HTML itself and, while a block quote or a list item is written, for a copy of it at the end of the buffer, one for each level the block lies in, none longer than the text. `s` is not the buffer.

### 16.12.2 Reading by blocks

(4) `s md.next` reads the first block of `s` and gives `(kind int, level int, text str, rest str)` (`or fail`); at the end it fails with `err.not_found`. Nothing is copied: `text` is a view of `s`. `kind` is one of the constants below, `text` what the table says, and `level` the level of a heading (1 to 6), 1 for an ordered list and 0 for the others.

| **Constant** | **text** |
|---|---|
| `md.heading` | the text of the heading, without its `#` and its underline, to be read as inline Markdown |
| `md.paragraph` | the lines of the paragraph, as written |
| `md.code` | fenced: the lines between the fences; indented: the lines as written, with their indentation |
| `md.quote` `md.list` `md.table` | the block as written, with its markers, to be given to `md.html` |
| `md.rule` | empty |

| **Word** | **Signature** | **Meaning** |
|---|---|---|
| `html` | `(s str, b buffer or fail)` | appends the HTML of the Markdown text `s`; `err.full` |
| `inline` | `(s str, b buffer or fail)` | appends the HTML of the text of one line or paragraph; `err.full` |
| `next` | `(s str gives kind int, level int, text str, rest str or fail)` | the first block of `s` and what is left after it; `err.not_found` at the end |
