# 19 The host interface

(1) The host interface is one C header, `pinax.h`. It uses only `<stddef.h>` and `<stdint.h>` and reads as C99, C23 and C++. This clause defines what its functions do; the comments in the header give more detail for each.

(2) One state is used by one thread at a time; states share nothing. A `pinax_str` a function returns is valid until the next call on that state unless stated otherwise.

## 19.1 Error codes

(1) Functions return a `pinax_err`; `PINAX_OK` is 0. Three outcomes are not failures: `PINAX_SUSPENDED` (the budget ran out, 19.5), `PINAX_WAITING` (every task waits for the host, 19.8) and `PINAX_PENDING` (a host word finishes later). From `0x100` come the faults and failures of scripts (the codes of 11.1); from `0x200` the failures of the interface itself: `ARGUMENT`, `NO_ROOM` (the block is too small), `SYNTAX`, `TYPE` (load refusals), `NOT_FOUND`, `SIGNATURE`, `FORMAT`, `STATE` (a call not allowed now).

(2) `pinax_error_text` gives the last failure as text; for a fault, in the form `module:line: name`.

## 19.2 Opening and closing

(1) `pinax_open(block, config, &state)` opens a state inside `block`. Fields of `config` that are 0 take the processor’s defaults: the slots of the banks, the size of the main run’s region, the number of handles alive at once, the instruction budget of a run (0 for none), the function that receives load diagnostics. When the block is too small the answer is `PINAX_ERR_NO_ROOM`, and `pinax_needed` tells the size that would have been enough.

(2) `config.hash_key` is the 16-byte key of the hash indexes use (8.10). A host that indexes text from outside gives a random key. All zeros means a fixed key.

(3) `pinax_close` closes the handles still open (calling their types’ close functions). It does not free the block; the block is the host’s.

## 19.3 Host words

(1) `pinax_register(state, module, defs, count)` registers host functions as the words of one module. Each entry of `defs` has a name, a signature text (in the form of 9.2, such as `"(s str gives n int or fail)"`), the function, a user pointer and flags. Signatures are checked once, here. Register words before the sources that use them.

(2) A host function receives `(call, user, args)`. Arguments and results are in arrays by type: integers (and `bool`, characters, handles and declared types over `int`) in `args->i[]` and `args->ri[]`, strings in `args->s[]` and `args->rs[]`, in the order of the signature, counted from 0 within each type. The integer pointers point straight at the state’s slots.

(3) When the function returns something other than `PINAX_OK`, a word whose signature has `or fail` fails with that code (11.2), and a word without it ends the run with a fault.

(4) A string result is copied into the caller’s region unless the word has the flag `PINAX_WORD_KEEP_STR`. Room for new bytes comes from `pinax_call_alloc`, in the caller’s region. A parameter of type `buffer` in the signature is a buffer of the script: `pinax_call_buffer` gives its free room and is told how many bytes were filled.

`19-host-words.c`

```c
#include "pinax.h"
#include <stdio.h>
#include <string.h>

/* (s str gives r str): the result is written into the caller's region. */
static pinax_err shout(pinax_call *call, void *user, const pinax_args *args) {
    (void)user;
    pinax_mem room = pinax_call_alloc(call, args->s[0].len + 1);
    if (!room.ptr)
        return PINAX_ERR_FULL;                       /* no `or fail`: this is a fault */
    unsigned char *out = room.ptr;
    for (size_t k = 0; k < args->s[0].len; ++k) {
        unsigned char c = args->s[0].ptr[k];
        out[k] = c >= 'a' && c <= 'z' ? (unsigned char)(c - 32) : c;
    }
    out[args->s[0].len] = '!';
    args->rs[0] = (pinax_str){out, args->s[0].len + 1};
    return PINAX_OK;
}

/* (s str gives n int or fail): an outcome other than PINAX_OK is the word's failure. */
static pinax_err digits(pinax_call *call, void *user, const pinax_args *args) {
    (void)call; (void)user;
    int64_t n = 0;
    if (args->s[0].len == 0)
        return PINAX_ERR_FORMAT;
    for (size_t k = 0; k < args->s[0].len; ++k) {
        unsigned char c = args->s[0].ptr[k];
        if (c < '0' || c > '9')
            return PINAX_ERR_FORMAT;
        n = n * 10 + (c - '0');
    }
    args->ri[0] = n;
    return PINAX_OK;
}

/* (b buffer or fail): writes straight into a buffer the script declared. */
static pinax_err stamp(pinax_call *call, void *user, const pinax_args *args) {
    (void)user;
    pinax_mem room = pinax_call_buffer(call, args->i[0], 0);
    if (room.len < 5)
        return PINAX_ERR_FULL;
    memcpy(room.ptr, "[ok] ", 5);
    pinax_call_buffer(call, args->i[0], 5);
    return PINAX_OK;
}

int main(void) {
    static unsigned char block[1 << 20];
    pinax_config config = {.struct_size = sizeof config};
    pinax_state *st;
    if (pinax_open((pinax_mem){block, sizeof block}, &config, &st) != PINAX_OK)
        return 1;
    static const pinax_word_def words[] = {
        {"shout", "(s str gives r str)", shout, NULL, 0},
        {"digits", "(s str gives n int or fail)", digits, NULL, 0},
        {"stamp", "(b buffer or fail)", stamp, NULL, 0},
    };
    pinax_register(st, "app", words, 3);
    static const char source[] =
        "use app\n"
        "buffer line 32\n"
        "word demo (gives s str)\n"
        "  line clear\n"
        "  line app.stamp or_else (e) end\n"
        "  \"12x\" app.digits or_else (e) -1 end to n\n"
        "  cat (\"hello\" app.shout, \" \", \"42\" app.digits or_else (e) -1 end, \" \", n) line append or_else (e) end\n"
        "  line contents\n"
        "end\n";
    if (pinax_load(st, "main", (pinax_str){(const unsigned char *)source, sizeof source - 1}, PINAX_LOAD_CODE) != PINAX_OK)
        return 1;
    pinax_word w;
    pinax_str out;
    if (pinax_find(st, "demo", "(gives s str)", 0, &w) != PINAX_OK)
        return 1;
    pinax_run(st, w, &(pinax_args){.rs = &out});
    printf("%.*s\n", (int)out.len, (const char *)out.ptr);
    pinax_close(st);
    return 0;
}
```

*Output*

```text
$ ./19-host-words
[ok] HELLO! 42 -1
```

## 19.4 Loading and lines

(1) `pinax_load(state, name, source, mode)` loads a source (5.2). `name` is the module’s name; the modes are `PINAX_LOAD_CODE` and `PINAX_LOAD_DATA` (13.4). A refusal is `PINAX_ERR_SYNTAX` or `PINAX_ERR_TYPE`, and the diagnostic arrives at `config.diag` as (file, line, column, text).

(2) `pinax_eval(state, text)` runs one line as a session does. All lines form one module (the session). What a line leaves is read with `pinax_eval_count` and `pinax_eval_value`.

## 19.5 Finding and running

(1) `pinax_find(state, name, signature, flags, &word)` finds a word and checks that its signature is the one given; another is `PINAX_ERR_SIGNATURE`. A bare name is a word of the first source loaded; `module.word` a word of that module (exported or not).

(2) `pinax_run(state, word, args)` runs a word. When the budget runs out it returns `PINAX_SUSPENDED`, and `pinax_resume` goes on where it stopped; the budget does not change results. A fault returns its code, and the state takes the next run.

(3) While a run is stopped (`PINAX_SUSPENDED`, `PINAX_WAITING`), a new `pinax_run` is `PINAX_ERR_STATE`. No function drops a stopped run: the host either continues it to its end, or closes the state and opens it again from an image saved earlier (19.9).

`19-run.c`

```c
#include "pinax.h"
#include <stdio.h>
#include <string.h>

static void load(pinax_state *st, const char *text) {
    if (pinax_load(st, "main", (pinax_str){(const unsigned char *)text, strlen(text)}, PINAX_LOAD_CODE) != PINAX_OK) {
        pinax_str why = pinax_error_text(st);
        printf("refused: %.*s\n", (int)why.len, (const char *)why.ptr);
    }
}

int main(void) {
    static unsigned char block[1 << 20];
    pinax_config config = {.struct_size = sizeof config, .budget = 1000};   /* instructions per run or resume */
    pinax_state *st;
    if (pinax_open((pinax_mem){block, sizeof block}, &config, &st) != PINAX_OK)
        return 1;
    load(st,
         "word total (n int gives r int) 0 to s  1 n 1 add range do (i int) s i add to s end each  s end\n"
         "word ratio (a int, b int gives r int) a 100 mul b div end\n");

    pinax_word w;
    /* the signature asked for must be the word's */
    printf("find with another signature: %s\n",
           pinax_find(st, "total", "(gives r int)", 0, &w) == PINAX_ERR_SIGNATURE ? "PINAX_ERR_SIGNATURE" : "?");
    pinax_find(st, "total", "(n int gives r int)", 0, &w);
    int64_t n = 100000, r = 0;
    pinax_args args = {.i = &n, .ri = &r};
    int resumes = 0;
    pinax_err err = pinax_run(st, w, &args);
    while (err == PINAX_SUSPENDED) {                 /* the budget ran out: go on where it stopped */
        ++resumes;
        err = pinax_resume(st, &args);
    }
    printf("total(100000) = %lld after %s resumes\n", (long long)r, resumes > 10 ? "many" : "few");

    /* a fault comes back as the error code, with its place in the error text */
    pinax_find(st, "ratio", "(a int, b int gives r int)", 0, &w);
    int64_t ab[2] = {3, 0};
    err = pinax_run(st, w, &(pinax_args){.i = ab, .ri = &r});
    pinax_str why = pinax_error_text(st);
    printf("ratio(3, 0): %s, \"%.*s\"\n", err == PINAX_ERR_DIV_ZERO ? "PINAX_ERR_DIV_ZERO" : "?", (int)why.len, (const char *)why.ptr);

    /* the state is still usable */
    ab[1] = 4;
    err = pinax_run(st, w, &(pinax_args){.i = ab, .ri = &r});
    printf("ratio(3, 4) = %lld\n", (long long)r);

    /* one line at a time, as a session does */
    const char *line = "6 7 mul \"done\"";
    if (pinax_eval(st, (pinax_str){(const unsigned char *)line, strlen(line)}) == PINAX_OK) {
        for (uint32_t k = 0; k < pinax_eval_count(st); ++k) {
            pinax_value v;
            pinax_eval_value(st, k, &v);
            if (v.kind == PINAX_VALUE_INT)
                printf("value %u: %lld (%.*s)\n", k, (long long)v.i, (int)v.type.len, (const char *)v.type.ptr);
            else
                printf("value %u: %.*s (%.*s)\n", k, (int)v.s.len, (const char *)v.s.ptr, (int)v.type.len, (const char *)v.type.ptr);
        }
    }
    pinax_close(st);
    return 0;
}
```

```text
$ ./19-run

ratio(3, 0): PINAX_ERR_DIV_ZERO, "main:2: div_zero"
ratio(3, 4) = 75
```

(4) `pinax_run` may be called from inside a host word too. There it runs only words found with the flag `PINAX_FIND_NESTED`, and words that may yield (14.2) cannot be found with that flag.

## 19.6 Handles

(1) `pinax_handle_type` makes a handle type with a name and a close function; scripts use the name as a type in signatures. `pinax_handle_new` makes a handle of a C pointer, `pinax_handle_get` gives a handle’s pointer (NULL for a handle given back), and `pinax_handle_release` gives a handle back.

(2) A handle is a number and a generation (as in 8.9). A script cannot get an address from a handle. The handles a run that ends with a fault opened are closed by the state, calling their close functions.

`19-handles.c`

```c
#include "pinax.h"
#include <stdio.h>

typedef struct { int value; int open; } counter;
static counter pool_[4];
static uint32_t counter_type;

static void close_counter(void *object, void *user) {   /* called for handles the script never closed */
    (void)user;
    ((counter *)object)->open = 0;
    printf("closed by the state: counter at %d\n", ((counter *)object)->value);
}
static pinax_err c_new(pinax_call *call, void *user, const pinax_args *args) {
    (void)user;
    for (int k = 0; k < 4; ++k)
        if (!pool_[k].open) {
            pool_[k] = (counter){0, 1};
            pinax_handle h;
            pinax_err err = pinax_handle_new(pinax_call_state(call), counter_type, &pool_[k], &h);
            args->ri[0] = (int64_t)h;
            return err;
        }
    return PINAX_ERR_FULL;
}
static pinax_err c_bump(pinax_call *call, void *user, const pinax_args *args) {
    (void)user;
    counter *c = pinax_handle_get(pinax_call_state(call), counter_type, (pinax_handle)args->i[0]);
    if (!c)
        return PINAX_ERR_STALE;
    args->ri[0] = ++c->value;
    return PINAX_OK;
}
static pinax_err c_free(pinax_call *call, void *user, const pinax_args *args) {
    (void)user;
    counter *c = pinax_handle_get(pinax_call_state(call), counter_type, (pinax_handle)args->i[0]);
    if (c) {
        printf("freed by the script: counter at %d\n", c->value);
        c->open = 0;
    }
    return pinax_handle_release(pinax_call_state(call), counter_type, (pinax_handle)args->i[0]);
}

int main(void) {
    static unsigned char block[1 << 20];
    pinax_config config = {.struct_size = sizeof config};
    pinax_state *st;
    if (pinax_open((pinax_mem){block, sizeof block}, &config, &st) != PINAX_OK)
        return 1;
    pinax_handle_type(st, "counter", close_counter, NULL, &counter_type);
    static const pinax_word_def words[] = {
        {"new", "(gives owned counter or fail)", c_new, NULL, 0},
        {"bump", "(c counter gives n int)", c_bump, NULL, 0},
        {"free", "(c owned counter)", c_free, NULL, 0},
    };
    pinax_register(st, "ctr", words, 3);
    static const char source[] =
        "use ctr\n"
        "word twice (gives n int or fail)\n"
        "  ctr.new or_fail to c\n"
        "  c ctr.bump drop  c ctr.bump to n\n"
        "  c ctr.free\n"
        "  n\n"
        "end\n"
        "word broken (gives n int or fail)\n"
        "  ctr.new or_fail to c\n"
        "  c ctr.bump 0 div to n\n"            /* a fault while the counter is open */
        "  c ctr.free\n"
        "  n\n"
        "end\n";
    if (pinax_load(st, "main", (pinax_str){(const unsigned char *)source, sizeof source - 1}, PINAX_LOAD_CODE) != PINAX_OK)
        return 1;
    pinax_word w;
    int64_t n = 0;
    pinax_find(st, "twice", "(gives n int or fail)", 0, &w);
    pinax_run(st, w, &(pinax_args){.ri = &n});
    printf("twice = %lld\n", (long long)n);
    pinax_find(st, "broken", "(gives n int or fail)", 0, &w);
    pinax_err err = pinax_run(st, w, &(pinax_args){.ri = &n});
    printf("broken: %s\n", err == PINAX_ERR_DIV_ZERO ? "PINAX_ERR_DIV_ZERO" : "?");
    pinax_close(st);
    return 0;
}
```

*Output*

```text

twice = 2
closed by the state: counter at 1
broken: PINAX_ERR_DIV_ZERO
```

## 19.7 Binding

(1) `pinax_bind(state, global, memory, bytes)` changes the storage of a global declared `bound` (8.12) to host memory; the size shall match the declaration. Script and host read and write the same bytes without copying. `pinax_global_find` tells where a declared global is and how large it is.

`19-bind.c`

```c
#include "pinax.h"
#include <stdio.h>

int main(void) {
    static unsigned char block[1 << 20];
    pinax_config config = {.struct_size = sizeof config};
    pinax_state *st;
    if (pinax_open((pinax_mem){block, sizeof block}, &config, &st) != PINAX_OK)
        return 1;
    static const char source[] =
        "bound array samples int 5\n"
        "bound global scale int\n"
        "word scaled_sum (gives n int) samples sum scale mul end\n"
        "word clear_first () 0 0 to samples end\n";
    if (pinax_load(st, "main", (pinax_str){(const unsigned char *)source, sizeof source - 1}, PINAX_LOAD_CODE) != PINAX_OK)
        return 1;
    static int64_t samples[5] = {1, 2, 3, 4, 5};    /* host memory the script reads and writes in place */
    static int64_t scale = 10;
    pinax_bind(st, "samples", samples, sizeof samples);
    pinax_bind(st, "scale", &scale, sizeof scale);
    pinax_word w;
    int64_t n = 0;
    pinax_find(st, "scaled_sum", "(gives n int)", 0, &w);
    pinax_run(st, w, &(pinax_args){.ri = &n});
    printf("scaled_sum = %lld\n", (long long)n);
    samples[4] = 105;                                /* the host changes it; no copy to refresh */
    pinax_run(st, w, &(pinax_args){.ri = &n});
    printf("after the host wrote samples[4]: %lld\n", (long long)n);
    pinax_find(st, "clear_first", "()", 0, &w);
    pinax_run(st, w, NULL);
    printf("after the script wrote cell 0: samples[0] = %lld\n", (long long)samples[0]);
    pinax_close(st);
    return 0;
}
```

*Output*

```text
$ ./19-bind
scaled_sum = 150
after the host wrote samples[4]: 1150
after the script wrote cell 0: samples[0] = 0
```

## 19.8 Host words that finish later

(1) A host word registered with `PINAX_WORD_AWAITABLE` may start some work, take a token with `pinax_call_pending`, and return `PINAX_PENDING`. The task that called it waits and others run. When nothing else can run, `pinax_run` or `pinax_resume` returns `PINAX_WAITING`. The host finishes the work with `pinax_complete(state,token, outcome, values)` and calls `pinax_resume`.

`19-await.c`

```c
#include "pinax.h"
#include <stdio.h>

/* A host word that finishes later: it starts the work, keeps a token and returns PINAX_PENDING. */
static pinax_token waiting[4];
static int64_t asked[4];
static int n_waiting;
static pinax_err fetch(pinax_call *call, void *user, const pinax_args *args) {
    (void)user;
    asked[n_waiting] = args->i[0];
    waiting[n_waiting++] = pinax_call_pending(call);
    return PINAX_PENDING;
}

int main(void) {
    static unsigned char block[1 << 20];
    pinax_config config = {.struct_size = sizeof config};
    pinax_state *st;
    if (pinax_open((pinax_mem){block, sizeof block}, &config, &st) != PINAX_OK)
        return 1;
    static const pinax_word_def words[] = {{"fetch", "(n int gives r int or fail)", fetch, NULL, PINAX_WORD_AWAITABLE}};
    pinax_register(st, "net", words, 1);
    static const char source[] =
        "use net\n"
        "tasks workers 2\n"
        "list got int 4\n"
        "word both (gives r int)\n"
        "  do 1 net.fetch or_else (e) -1 end got push or_else (e) end end workers spawn or_else (e) 0 return end drop\n"
        "  do 2 net.fetch or_else (e) -1 end got push or_else (e) end end workers spawn or_else (e) 0 return end drop\n"
        "  workers run_all\n"
        "  got sum\n"
        "end\n";
    if (pinax_load(st, "main", (pinax_str){(const unsigned char *)source, sizeof source - 1}, PINAX_LOAD_CODE) != PINAX_OK)
        return 1;
    pinax_word w;
    int64_t r = 0;
    pinax_args args = {.ri = &r};
    pinax_find(st, "both", "(gives r int)", 0, &w);
    pinax_err err = pinax_run(st, w, &args);
    printf("run: %s, %d operations started\n", err == PINAX_WAITING ? "PINAX_WAITING" : "?", n_waiting);
    /* the host finishes them in its own time, here the second first */
    for (int k = n_waiting - 1; k >= 0; --k) {
        int64_t result = asked[k] * 100;
        pinax_complete(st, waiting[k], PINAX_OK, &(pinax_args){.ri = &result});
    }
    err = pinax_resume(st, &args);
    printf("resume: %s, both = %lld\n", err == PINAX_OK ? "PINAX_OK" : "?", (long long)r);
    pinax_close(st);
    return 0;
}
```

*Output*

```text
$ ./19-await
run: PINAX_WAITING, 2 operations started
resume: PINAX_OK, both = 300
```

## 19.9 Images and clones

(1) An **image** is a whole state: code, declarations, globals, slots, regions, stopped runs and tasks. `pinax_image_save` writes it and `pinax_image_open` opens it. An image that lies at the start of the block is opened in place, without copying. An image of another format, or of another build’s memory layout, is `PINAX_ERR_FORMAT`.

(2) On an opened state the host gives host words, handle types and `extern` functions again, by name. Until all are given, runs are refused with `PINAX_ERR_NOT_FOUND`. Handles come back closed (without their close functions), and bound globals back on their own storage. `pinax_clone` saves and opens in another block in one call.

`19-image.c`

```c
#include "pinax.h"
#include <stdio.h>
#include <stdlib.h>

static pinax_err twice(pinax_call *call, void *user, const pinax_args *args) {
    (void)call; (void)user;
    args->ri[0] = args->i[0] * 2;
    return PINAX_OK;
}
static const pinax_word_def words[] = {{"twice", "(n int gives r int)", twice, NULL, 0}};

static int64_t call_next(pinax_state *st) {
    pinax_word w;
    int64_t r = 0;
    if (pinax_find(st, "next", "(gives r int)", 0, &w) != PINAX_OK)
        return -1;
    pinax_err err = pinax_run(st, w, &(pinax_args){.ri = &r});
    return err == PINAX_OK ? r : -(int64_t)err;
}

int main(void) {
    static _Alignas(16) unsigned char a[1 << 20], b[1 << 20], c[1 << 20];
    pinax_config config = {.struct_size = sizeof config};
    pinax_state *st;
    if (pinax_open((pinax_mem){a, sizeof a}, &config, &st) != PINAX_OK)
        return 1;
    pinax_register(st, "host", words, 1);
    static const char source[] =
        "use host\n"
        "global calls int\n"
        "word next (gives r int) calls 1 add to calls  calls host.twice end\n";
    if (pinax_load(st, "main", (pinax_str){(const unsigned char *)source, sizeof source - 1}, PINAX_LOAD_CODE) != PINAX_OK)
        return 1;
    call_next(st);
    printf("in the first state: %lld\n", (long long)call_next(st));

    /* save the whole state: code, globals, everything */
    size_t size = pinax_image_size(st), written = 0;
    unsigned char *image = malloc(size);
    pinax_image_save(st, (pinax_mem){image, size}, &written);

    /* open it in another block; host words are given again by name */
    pinax_state *copy;
    if (pinax_image_open((pinax_mem){b, sizeof b}, (pinax_str){image, written}, &config, &copy) != PINAX_OK)
        return 1;
    printf("before the host word is given again: %s\n", call_next(copy) == -PINAX_ERR_NOT_FOUND ? "PINAX_ERR_NOT_FOUND" : "?");
    pinax_register(copy, "host", words, 1);
    printf("the copy goes on: %lld\n", (long long)call_next(copy));
    printf("the first state is its own: %lld\n", (long long)call_next(st));

    /* a clone is the same in one call */
    pinax_state *twin;
    if (pinax_clone(copy, (pinax_mem){c, sizeof c}, &twin) != PINAX_OK)
        return 1;
    pinax_register(twin, "host", words, 1);
    printf("the clone of the copy: %lld\n", (long long)call_next(twin));
    free(image);
    pinax_close(twin);
    pinax_close(copy);
    pinax_close(st);
    return 0;
}
```

*Output*

```text
$ ./19-image
in the first state: 4
before the host word is given again: PINAX_ERR_NOT_FOUND
the copy goes on: 6
the first state is its own: 6
the clone of the copy: 8
```

## 19.10 Measuring, and the locals of a fault

(1) `pinax_stats_get` gives the highest use of slots, region, handles and call depth, and the number of instructions run. It is for choosing the block and the capacities.

(2) `pinax_fault_local` gives, after a run that ended with a fault, the locals of the word the fault happened in with their values at that time (up to 16; text cut to its first 32 bytes). They are what `pnx` shows below a fault (11.3).
