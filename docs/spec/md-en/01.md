# 1 Scope

(1) This document defines a **processor**.

#### Constraints

(2) A word that takes a string cannot be given an integer.

`hello.pnx`

```pinax
use io
"hello, world" io.println
```

*Output*

```text
$ pnx hello.pnx
hello, world
```

`hello-refused.pnx`

```pinax
use io
42 io.println
```

*Refused*

```text
$ pnx hello-refused.pnx
hello-refused.pnx:2:4: an argument has another type than the word's signature asks for
```
