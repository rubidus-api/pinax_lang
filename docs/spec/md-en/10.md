# 10 Control

#### Syntax

```ebnf
control = "if" { body } [ "else" { body } ] "end"
        | "loop" [ "(" NAME ")" ] { body } "end"
        | "case" { branch } [ "otherwise" { body } "end" ] "end" ;
branch  = values "of" { body } "end" ;
values  = case-value | "(" case-value { "," case-value } ")" ;
leave   = ( "while" | "until" | "break" ) [ "(" NAME ")" ] | "return" ;
block   = "do" [ "(" effect ")" ] { body } "end" ;
```

(1) `end` closes the innermost open construct. The words that open one are `word` `test` `record` `do` `if` `loop` `case` `of` `otherwise` `or_else`.

(2) At load a processor compares the stacks of all paths. Where paths meet again, the stack shall be the same whichever path was taken. A **leaving branch** — one that ends with `return`, `fail`, `break` or a loop that never ends — is not compared.

## 10.1 Branches

(1) `condition if body end` takes the `bool` on top and runs the body when it is true. `condition if body elsebody end` runs the `else` body when it is false.

(2) The body of an `if` without `else` shall leave the stack as it found it. With `else`, the two bodies shall leave the same stack.

`10-if.pnx`

```pinax
use io
word sign (n int gives str) n 0 lt if "negative" else n 0 eq if "zero" else "positive" end end end
-5 sign io.println
0 sign io.println
word warn (n int) n 100 gt if "big" io.println end end      rem no else: the branch leaves the stack as it was
500 warn
```

*Output*

```text
$ pnx 10-if.pnx
negative
zero
big
```

#### Constraints

(3) Two branches that leave different stacks are refused.

`10-if-unequal.pnx`

```pinax
word f (n int gives int) n 0 lt if 1 2 else 3 end end
```

*Refused*

```text
$ pnx 10-if-unequal.pnx
10-if-unequal.pnx:1:47: the two branches of this if leave different stacks
```

## 10.2 Loops

(1) `loop body end` repeats its body. Inside it, these words leave the loop:

- `condition while` — leaves when the condition is false;
- `condition until` — leaves when the condition is true;
- `break` — leaves without a condition.

Each may be used any number of times, directly in the body of the loop or inside a branch in it (`if` `else` `case` `or_else`). They leave the innermost loop.

(2) One turn shall leave the stack as it found it, and at every place where the loop is left the stack shall be as it was when the loop was entered. A result of a loop is kept in a local.

`10-loop.pnx`

```pinax
use io
use str
word digits (n int gives int)            rem how many decimal digits
  1 to count_
  loop
    n 10 div to n
    n 0 eq until
    count_ 1 add to count_
  end
  count_
end
12345 digits str.to_str io.println
word first_square_over (limit int gives int)
  1 to i
  loop
    i i mul limit gt if break end
    i 1 add to i
  end
  i
end
50 first_square_over str.to_str io.println
```

*Output*

```text
$ pnx 10-loop.pnx
5
8
```

(3) `loop (NAME)` names a loop. `while (NAME)`, `until (NAME)` and `break (NAME)` leave everything up to that loop at once. The name is visible only inside the loop’s body and is not a value. It follows the rule against hiding (9.5).

`10-loop-named.pnx`

```pinax
use io
use str
word find_pair (target int gives str)      rem the first a, b in 1..9 with a*b = target
  1 to a
  0 to b
  loop (rows)
    1 to b
    loop
      a b mul target eq until (rows)       rem leaves both loops at once
      b 1 add to b
      b 9 gt until
    end
    a 1 add to a
    a 9 gt if "none" return end
  end
  cat (a, " x ", b)
end
42 find_pair io.println
```

*Output*

```text
$ pnx 10-loop-named.pnx
6 x 7
```

(4) A loop with no `while`, `until` or `break` that leaves it never ends. A loop that never ends counts as a leaving branch, so a word does not need results after it. An `until` of an inner loop does not count as leaving the outer one, but an `until (outer name)` written in the inner loop does.

`10-forever.pnx`

```pinax
use io
use str
word first_multiple (n int, k int gives int)     rem a loop with no exit counts as leaving
  loop
    n k mod 0 eq if n return end
    n 1 add to n
  end
end
100 7 first_multiple str.to_str io.println
```

*Output*

```text
$ pnx 10-forever.pnx
105
```

#### Constraints

(5) A turn that changes the stack is refused.

`10-loop-net.pnx`

```pinax
word f (gives int)
  0
  loop
    1 add
    dup 10 gt until
    1
  end
end
```

*Refused*

```text
$ pnx 10-loop-net.pnx
10-loop-net.pnx:7:3: one turn of a loop must leave the stack as it found it
```

(6) `while`, `until` or `break` outside a loop is refused. They cannot leave an outer loop from inside a `do` block either.

`10-while-outside.pnx`

```pinax
word f (n int) n 0 gt while end
```

*Refused*

```text
$ pnx 10-while-outside.pnx
10-while-outside.pnx:1:23: while, until and break belong inside a loop
```

(7) Code right after a leaving word (`return` `fail` `break`) or a loop that never ends, in the same branch, can never be reached and is refused.

`10-unreachable.pnx`

```pinax
word f (n int gives int) n return 1 add end
```

*Refused*

```text
$ pnx 10-unreachable.pnx
10-unreachable.pnx:1:35: this code cannot be reached: the code before it always leaves
```

## 10.3 Choosing

(1) `value case branches… end` takes the `int` or `str` on top, compares it with the values of the branches and runs the body of the first equal one. The values of a branch are literals or `const`s of this source; several values go in parentheses with commas. When no branch matches, the `otherwise` body runs. Every branch shall leave the same stack.

`10-case.pnx`

```pinax
use io
const quit_code 9
word describe (cmd str gives str)
  cmd case
    "add" of "adds a line" end
    ("rm", "del") of "deletes a line" end
    otherwise "unknown command" end
  end
end
word level (n int gives str)
  n case
    0 of "off" end
    1 of "low" end
    quit_code of "quit" end
    otherwise "high" end
  end
end
"del" describe io.println
"mv" describe io.println
9 level io.println
```

*Output*

```text
$ pnx 10-case.pnx
deletes a line
unknown command
quit
```

#### Constraints

(2) The same value in two branches is refused.

`10-case-twice.pnx`

```pinax
word f (n int gives int) n case 1 of 10 end 1 of 20 end otherwise 0 end end end
```

*Refused*

```text
$ pnx 10-case-twice.pnx
10-case-twice.pnx:1:45: this value is already in an earlier branch of the case
```

(3) A constant of a module (a path such as `json.key` or `err.full`) cannot be a branch value; compare such values with `eq`.

`10-case-path.pnx`

```pinax
use json
word f (k int gives bool) k case json.key of true end otherwise false end end end
```

*Refused*

```text
$ pnx 10-case-path.pnx
10-case-path.pnx:2:34: a case value is a literal or the name of a const
```

#### Faults

(4) With no `otherwise` and no matching branch, the fault is `range`.

`10-case-nomatch.pnx`

```pinax
use io
word f (n int gives str) n case 1 of "one" end 2 of "two" end end end
2 f io.println
3 f io.println
```

*Fault*

```text
$ pnx 10-case-nomatch.pnx
two
10-case-nomatch.pnx:2: index out of range
  n int = 3
```

## 10.4 Returning

(1) `return` ends the word on the spot. The stack there shall match the results (9.2 (4)).

#### Constraints

(2) `return` is used only inside a definition (a word, a block value, a test). In code outside definitions it is refused.

`10-return-outside.pnx`

```pinax
use io
"start" io.println
return
```

*Refused*

```text
$ pnx 10-return-outside.pnx
10-return-outside.pnx:3:1: return belongs inside a definition
```

## 10.5 Blocks

(1) `do … end` is a **block**. A block is used in two ways; the form is the same, and what takes the block decides.

- An **inline block** — a block given directly to a combining word (10.6). It is expanded in place, so it can read and store the locals around it, and a `return` inside it leaves the word around it.
- A **block value** — a block stored in a local, or given to a parameter of type `word (signature)` . It becomes a nameless word, called with `call` . It does not see the locals around it (it captures nothing); it sees globals.

(2) A signature may follow `do`; its names become locals of the block, as in a word definition. When what takes the block fixes its effect, the signature may be left out.

`10-inline-locals.pnx`

```pinax
use io
use str
word total_over (limit int gives int)
  0 to acc
  1 10 range do (i int) i limit gt if acc i add to acc end end each   rem the block sees acc and limit
  acc
end
5 total_over str.to_str io.println
```

*Output*

```text
$ pnx 10-inline-locals.pnx
30
```

`10-value-block.pnx`

```pinax
use io
use str
word twice (n int, f word (int gives int) gives int) n f call f call end
5 do (x int gives int) x 3 mul end twice str.to_str io.println
word add_one (int gives int) 1 add end
word demo (gives int)
  do (x int gives int) x add_one end to step     rem a block value in a local
  41 step call
end
demo str.to_str io.println
```

*Output*

```text
$ pnx 10-value-block.pnx
45
42
```

#### Constraints

(3) A block value that uses a local from outside is refused (the name is not declared inside the block).

`10-value-block-outer.pnx`

```pinax
word twice (n int, f word (int gives int) gives int) n f call f call end
word scale (k int gives int) 5 do (x int gives int) x k mul end twice end
```

*Refused*

```text
$ pnx 10-value-block-outer.pnx
10-value-block-outer.pnx:2:55: this name is not declared before this place
```

(4) A block expanded into a loop (`each`, `times` and so on) shall leave the stack as it found it.

`10-block-net.pnx`

```pinax
array xs int 3
word f (gives int) 0 xs do (x int) x end each end
```

*Refused*

```text
$ pnx 10-block-net.pnx
10-block-net.pnx:2:38: this block must leave the stack as it found it
```

## 10.6 Stems and combining words

(1) A **stem** yields values one after another. A stem is not a value: it cannot be stored, and the combining word right after it shall take it. Together they make one loop. These make stems:

| **Stem** | **Elements** |
|---|---|
| the name of an array or list | the cells’ values (rows, for records); a list up to its length. Queues, pools, buffers and indexes are not stems |
| `lo hi range` | the `int`s from `lo` up to but not including `hi` |
| `s sep str.split`, `s str.lines`, `s str.words`, `s str.chars` | `str` views (16.1); `chars` one UTF-8 character each |
| `s str.bytes` | `int`: the bytes (16.1) |
| `s pat ptn.matches`, `s re rex.matches`, `s re rex.split` | the parts matched (16.6, 16.7) |
| `s csv.fields` | the fields (16.9) |

(2) The combining words are below; the “block” column is what the block takes and gives.

| **Word** | **Block** | **Result** |
|---|---|---|
| `each` | `(T)` | none |
| `each_index` | `(T, i int)` | none |
| `fold` | `(acc U, T gives U)` | `U`; the first value goes before the stem: `0 xs do … end fold` |
| `count` | `(T gives bool)` | `int` |
| `any` `all` | `(T gives bool)` | `bool`; stops early once the answer is known |
| `first` | `(T gives bool)` | `T or fail`; `err.not_found` when none |
| `sum` | none | `int` (of a stem of `dec(N)`, a `dec(N)`); an overflow is the fault `overflow` |
| `minimum` `maximum` | none | `int or fail` (`dec(N)` likewise); `err.not_found` for an empty stem |
| `map_into` | `(T gives U)` | a destination after it; `or fail` |
| `filter_into` | `(T gives bool)` | a destination after it; `or fail` |
| `n times` | `()` | none; no stem, `n` times |

`10-combinators.pnx`

```pinax
use io
use str
array scores int 6
assign scores (72, 95, 88, 61, 90, 79)
scores sum str.to_str io.println
scores do (s int gives bool) s 90 ge end count str.to_str io.println
scores do (s int gives bool) s 60 lt end any if "someone failed" else "all passed" end io.println
0 scores do (acc int, s int gives int) acc s max end fold str.to_str io.println
scores do (s int, i int) i 2 lt if cat ("#", i, " ", s) io.println end end each_index
1 5 range do (i int) i str.to_str io.print end each
"" io.println
3 do "x" io.print end times
"" io.println
```

*Output*

```text
$ pnx 10-combinators.pnx
485
2
all passed
95
#0 72
#1 95
1234
xxx
```

`10-first.pnx`

```pinax
use io
use str
array xs int 5
assign xs (3, 8, 12, 5, 20)
xs do (x int gives bool) x 10 gt end first or_else (e) -1 end str.to_str io.println
xs do (x int gives bool) x 100 gt end first or_else (e) -1 end str.to_str io.println
xs minimum or_else (e) 0 end str.to_str io.println
```

*Output*

```text
$ pnx 10-first.pnx
12
-1
3
```

(3) `map_into` and `filter_into` make no new storage; they write into the destination. A list destination is pushed onto and nothing is given. An array destination is written from cell 0, and the number of cells written is given (`gives n int or fail`). When the destination is full, they fail with `err.full`; what was written stays.

`10-map-into.pnx`

```pinax
use io
use str
array xs int 4
assign xs (1, 2, 3, 4)
list squares int 4
array evens int 4
word go (or fail)
  xs do (x int gives int) x x mul end squares map_into or_fail
  xs do (x int gives bool) x 2 mod 0 eq end evens filter_into or_fail to n
  cat ("squares ", 3 squares idx, ", evens written ", n) io.println
end
go or_else (e) e err_text io.println end
```

*Output*

```text
$ pnx 10-map-into.pnx
squares 16, evens written 2
```

## 10.7 Deferred code

#### Syntax

```ebnf
defer = "defer" { body } "end" ;
```

(1) `defer CODE end` writes code that runs when the enclosing block is left. The block is a word’s body, a loop’s body (at every turn) or the `do` block of a combining word (at every run). The code runs on every way out of that block: the block’s `end`, the end of a turn, `break`, a `while` or `until` that leaves the loop, `return`, `or_return`, `or_fail` and `fail`. Several run in the reverse of the order they are written. They do not run when a fault ends the run (the state closes the handles then, 19.6).

`10-defer.pnx`

```pinax
use io
use str
buffer trace 256
word say (s str) s trace append or_else (e) end end
rem Every way out of a block runs its defers, the last written first.
word step (n int or fail)
  "open " say
  defer "close " say end
  defer "flush " say end
  n 0 lt if err.range fail end
  "work " say
end
1 step or_else (e) end
-1 step or_else (e) "(failed) " say end
trace contents str.trim io.println
```

*Output*

```text
$ pnx 10-defer.pnx
open work flush close open flush close (failed)
```

(2) When deferred code gives an owned value (`m release`, `f file.close`), the defer takes that value over. It counts as given on every way out of the block, so no failure path needs code of its own to close it. Inside the block the value can still be lent.

`10-defer-owned.pnx`

```pinax
use io
use str
buffer report 4096
rem A mark taken back at the end of every turn, also when append fails.
word build (or fail)
  1 50 range do (i int)
    mark to m
    defer m release end
    cat ("row ", i, ": ", i i mul, "\n") report append or_fail
  end each
end
build or_else (e) cat ("full: ", e err_text) io.println end
cat ("report: ", report len, " bytes") io.println
```

*Output*

```text
$ pnx 10-defer-owned.pnx
report: 585 bytes
```

#### Constraints

(3) `defer` is written right in a word’s body, a loop’s body or a `do` block. In a branch of `if`, `case` or `or_else`, or outside a definition, it is refused.

`10-defer-branch.pnx`

```pinax
word f (c bool)
  c if defer end end
end
```

*Refused*

```text
$ pnx 10-defer-branch.pnx
10-defer-branch.pnx:2:8: defer is written right in a word's body, a loop's body or a do block, not in a branch
```

(4) Deferred code leaves the stack as it found it and leaves nothing on it. It cannot hold `return` `fail` `break` `while` `until` `to` `set` `loop` `do` `case` `defer`, or `or_fail` `or_return`; a word that can fail is taken with `or_else` inside it.

(5) Giving an owned value that a defer took over, inside the block, is refused.

`10-defer-taken.pnx`

```pinax
word twice (gives int)
  mark to m
  defer m release end
  m release
  0
end
```

*Refused*

```text
$ pnx 10-defer-taken.pnx
10-defer-taken.pnx:4:5: a defer gives this owned value when the block is left; here it can only be lent
```

#### Diagnostics

| **Condition** | **Message** |
|---|---|
| Two branches leave different stacks | `the two branches of this if leave different stacks` |
| A turn changes the stack | `one turn of a loop must leave the stack as it found it` |
| `while` `until` `break` outside a loop | `while, until and break belong inside a loop` |
| Unreachable code | `this code cannot be reached: the code before it always leaves` |
| The same value twice in a `case` | `this value is already in an earlier branch of the case` |
| An expanded block changes the stack | `this block must leave the stack as it found it` |
| `return` outside a definition | `return belongs inside a definition` |
| A branch value that is not a constant | `a case value is a literal or the name of a const` |
| A combining word on something that is not a stem | `only an array or a list is a stem (not a queue, a pool, a buffer or an index)` |
| `defer` in a branch | `defer is written right in a word's body, a loop's body or a do block, not in a branch` |
| `defer` outside a definition | `defer belongs inside a definition` |
| Deferred code changes the stack | `a defer leaves the stack as it found it` |
| A word that leaves, in deferred code | `a defer holds no return, fail, break, while, until, to, set, loop, do, case or defer` |
| `or_fail` `or_return` in deferred code | `a defer does not leave the word; a failure in it is taken with or_else` |
| Giving a value a defer took over | `a defer gives this owned value when the block is left; here it can only be lent` |
