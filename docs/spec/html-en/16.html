16 Standard modules

(1) The standard modules come with the processor. They are opened with use MODULE and written MODULE.WORD (13.1). Words of standard modules cannot reach outside without the host — they use no files, clocks or environment.

(2) Words of standard modules make no new storage. Their results are one of:

  • a view of the bytes they were given; nothing is copied;
  • a view of new bytes written in the region (12.2);
  • bytes appended to a buffer the caller gave. Such words end in _into or take a buffer, and fail with err.full when there is not enough room.

16.1 str — strings

(1) The module str works on strings as bytes. Byte positions count from 0. Only the words that work on characters (chars char_count is_utf8) read UTF-8. Changing case (upper lower) changes ASCII only.

(2) Where a separator or a part to look for is taken (sep, part), a str or a single character (int, 6.5) may be given.

(3) All results are views of the string given.

16.1.4 Stems and writing into buffers

(7) Words that make stems (10.6):

  • s sep str.split — the pieces between seps, empty ones included;
  • s str.words — the pieces between white space, no empty ones;
  • s str.lines — the lines, without their LF or CR LF;
  • s str.bytes — the bytes (int);
  • s str.chars — one view (str) for each UTF-8 character.

(8) Words that write into a buffer:

  • sep buf STEM str.join_into — appends the pieces of the stem joined by sep (or fail). The stem goes last, since the word right after a stem shall take it;
  • s old new buf str.replace_into — appends the text with replacements and gives their number (gives n int or fail).

16.5.1 Records

(3) row buf bytes.pack appends one row of a record (8.8) to a buffer, field by field in order (or fail). s row bytes.unpack reads the fields from bytes into the row and gives the rest (gives str or fail). row bytes.packed_size is the number of bytes pack would write.

(4) The bytes of a field: an integer width as that width (most significant byte first when the record has big_endian, least significant first otherwise), int as 8 bytes, bool as 1 byte, varint as LEB128, str(N) as a length (varint) and the bytes, a field holding a row as the number it holds (varint).

(5) When pack fails the buffer goes back to the length it had before the call. unpack writes into the row only when every field can be read; when it fails the row is unchanged.

  "\x01\x02\x05" b bytes.unpack or_else (e) cat ("short input: ", e err_text) io.println "" end drop
  cat ("the row is unchanged: ", b item.name) io.println

16.6 ptn — small patterns

(1) The module ptn finds and replaces text with patterns of the size of Lua’s. It has no alternation (|), no repetition of groups and no back references; rex (16.7) takes the larger grammar.

16.6.1 The text of a pattern

(2) A pattern is a sequence of the items below, matched byte by byte.

16.7 rex — regular expressions

(1) The module rex finds and replaces with regular expressions. Its matching never goes back, so the time it takes is bounded by the length of the text times the size of the pattern. Write patterns as raw strings (6.5): in an ordinary string "\d" is refused as an unknown escape, and "\b" becomes a backspace.

(2) In a source that has use rex the type name regex is visible. A regex value is a pattern program that cannot be changed once made. It is used only in locals, arguments and results.

(3)

FormMeaning

(4) A pattern that repeats a body able to match the empty text (such as (a*)*) may give other captures than Perl or Python.

(6) When matches, split and replace search again from the next place, they still see the whole text, so ^ and \b know the bytes before that place.

16.8 json — JSON

(1) The module json reads and writes JSON (RFC 8259) text in one direction, without building a tree: it reads one token at a time and writes straight into a buffer.

16.8.1 Reading

(2) s json.next reads the first token of s and gives (kind int, value str, rest str) (or fail). At the end it fails with err.not_found; on something that is not a token, with err.format. White space, commas and colons between tokens are passed over. The structure of the grammar — matching brackets, where commas go — is not checked.

(3) kind is one of the constants below. The value of a string is its text without the quotes; when it has escapes, they are decoded into text written in the region. The value of a number is its text as written.

ConstantToken
json.object json.object_end{ }
json.array json.array_end[ ]
json.keya string followed by a colon
json.stringany other string
json.numbera number
json.boolean json.nulltrue false, null

(4) s json.skip passes over one value (with everything inside, for an object or array) and gives the rest (gives str or fail).

16-json-read.pnx

use io
use json
word kind_name (k int gives str)                    rem the kinds are constants of json
  k json.key eq if "key" return end
  k json.string eq if "string" return end
  k json.number eq if "number" return end
  k json.boolean eq if "boolean" return end
  k json.null eq if "null" return end
  k json.object eq k json.array eq or if "open" return end
  "close"
end
word tokens (s str)
  s to rest
  loop
    rest json.next or_else (e) break end to (kind, value, rest)
    cat (kind kind_name, " ", value) io.println
  end
end
text END

END

16.9 csv — CSV

(1) The module csv reads and writes CSV in the form of RFC 4180: fields are separated by commas; a field that holds a comma, a quote or a line break is quoted, and quotes inside it are doubled.

(2) s csv.fields is a stem (10.6) of the fields of one line. A quoted field is given without its quotes and with doubled quotes made single. An unclosed quote gives the rest of the text as the last field (a stem cannot report a failure).

(3) The writing words append to a buffer (or fail, err.full when there is not enough room). s buf csv.put, n buf csv.put_int and b buf csv.put_bool append one field (with the comma it needs); buf csv.end_line ends the line. Booleans are written true and false.

(4) row buf csv.pack appends one row of a record as one line. s row csv.unpack reads one line into the fields in order and gives what follows the line. The row is written only when every field is right (err.format).
