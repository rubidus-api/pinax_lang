17 Standard host modules

(1) The modules of this clause are host words that come with the processor. They are not part of the language: they exist only when a host registers them (13.3). pnx registers all five. A host that embeds the library picks them one by one with pinax_host_register(state, "io") and the like (library libpinax_host). Using a module that was not registered is refused (13.1).

(2) Host words keep the same rules as other words: their signatures are checked at load, words with or fail shall be guarded, and owned values are handed over exactly once.

17.1 io — standard input and output

(1)

WordSignatureMeaning
print println(s str)writes to standard output; println adds a line break (LF)
eprint(s str)writes to standard error
read_line(gives line str or fail)one line of standard input, without its line break; err.not_found at the end of input
read_line_into(buf buffer or fail)appends one line to a buffer

Bytes are written unchanged; the same bytes come out on every operating system.

17-io.pnx

use io
use str
word demo ()
  "no new line, " io.print
  "then one" io.println
  loop
    io.read_line or_else (e) break end to line         rem fails at the end of the input
    cat ("read: ", line, " (", line str.len, " bytes)") io.println
  end
end
demo

Output

$ pnx 17-io.pnx
no new line, then one
read: first line (10 bytes)
read: second line (11 bytes)

17.2 file — files

(1) The handle type file is an open file. The opening words give an owned file and close takes it (12.4).

WordSignatureMeaning
open_read open_write(path str gives owned file or fail)opens for reading; for writing (made new or emptied)
write(s str, f file or fail)writes bytes
read_line(f file gives line str or fail)one line; err.not_found at the end
read(f file, buf buffer gives n int or fail)reads into a buffer and gives the number of bytes read
read_line_into(f file, buf buffer or fail)appends one line to a buffer
read_all(path str gives body str or fail)reads a whole file into the region
read_all_into(path str, buf buffer or fail)appends a whole file to a buffer
close(f owned file)closes it

A missing file is err.not_found.

17-file.pnx

use io
use file
buffer buf 64
word demo (or fail)
  "data.txt" file.open_write or_fail to out
  "alpha\nbeta\n" out file.write or_else (e) out file.close e fail end
  out file.close
  "data.txt" file.open_read or_fail to in
  loop
    in file.read_line or_else (e) break end to line
    cat ("line: ", line) io.println
  end
  in file.close
  "data.txt" buf file.read_all_into or_fail
  cat ("all: ", buf contents) io.print
end
demo or_else (e) cat ("file error: ", e err_text) io.println end
"missing.txt" file.read_all or_else (e) cat ("missing.txt: ", e err_text) end io.println

Output

$ pnx 17-file.pnx
line: alpha
line: beta
all: alpha
beta
missing.txt: not_found

17.3 clock random env

(1)

WordSignatureMeaning
clock.now_ms(gives int)the time now, in milliseconds since 1970-01-01 UTC
clock.monotonic_ns(gives int)nanoseconds of a clock that never goes back
clock.sleep(ms int)waits; the state does nothing else meanwhile
random.seed(n int)sets the sequence; the same seed gives the same sequence
random.random(gives int)a 64-bit random number (not for cryptography)
random.random_below(n int gives int)from 0 to n−1
env.arg_count(gives int)the number of arguments; 0 is the program file
env.arg(i int gives s str or fail)argument i
env.getenv(name str gives s str or fail)an environment variable; err.not_found when unset

17-env.pnx

use io
use env
cat ("arguments: ", env.arg_count) io.println
0 env.arg_count range do (i int) i env.arg or_else (e) "?" end io.println end each
"PINAX_SURELY_UNSET" env.getenv or_else (e) cat ("not set: ", e err_text) end io.println

Output

$ pnx 17-env.pnx alpha beta
arguments: 3
17-env.pnx
alpha
beta
not set: not_found

17-random-clock.pnx

use io
use random
use clock
word demo ()
  42 random.seed                                       rem the same seed, the same numbers
  6 random.random_below to a
  a 0 ge a 6 lt and if "a die in 0..5" io.println end
  clock.monotonic_ns to t0
  clock.monotonic_ns to t1
  t1 t0 ge if "the monotonic clock does not go back" io.println end
end
demo

Output

$ pnx 17-random-clock.pnx
a die in 0..5
the monotonic clock does not go back
