17 Standard host modules

(1) The modules of this clause are host words that come with the processor. They are not part of the language: they exist only when a host registers them (13.3). pnx registers all five. A host that embeds the library picks them one by one with pinax_host_register(state, "io") and the like (library libpinax_host). Using a module that was not registered is refused (13.1).

(2) Host words keep the same rules as other words: their signatures are checked at load, words with or fail shall be guarded, and owned values are handed over exactly once.

17.1 io — standard input and output

(1)

WordSignatureMeaning
print println(s str)writes to standard output; println adds a line break (LF)
eprint(s str)writes to standard error
read_line(gives line str or fail)one line of standard input, without its line break; err.not_found at the end of input
read_line_into(buf buffer or fail)appends one line to a buffer

Bytes are written unchanged; the same bytes come out on every operating system.

17-io.pnx

use io
use str
word demo ()
  "no new line, " io.print
  "then one" io.println
  loop
    io.read_line or_else (e) break end to line         rem fails at the end of the input
    cat ("read: ", line, " (", line str.len, " bytes)") io.println
  end
end
demo

Output

$ pnx 17-io.pnx
no new line, then one
read: first line (10 bytes)
read: second line (11 bytes)

17.2 file — files

(1) The handle type file is an open file. The opening words give an owned file and close takes it (12.4).

WordSignatureMeaning
open_read open_write(path str gives owned file or fail)opens for reading; for writing (made new or emptied)
write(s str, f file or fail)writes bytes
read_line(f file gives line str or fail)one line; err.not_found at the end
read(f file, buf buffer gives n int or fail)reads into a buffer and gives the number of bytes read
read_line_into(f file, buf buffer or fail)appends one line to a buffer
read_all(path str gives body str or fail)reads a whole file into the region
read_all_into(path str, buf buffer or fail)appends a whole file to a buffer
close(f owned file)closes it

A missing file is err.not_found.

17-file.pnx

use io
use file
buffer buf 64
word demo (or fail)
  "data.txt" file.open_write or_fail to out
  "alpha\nbeta\n" out file.write or_else (e) out file.close e fail end
  out file.close
  "data.txt" file.open_read or_fail to in
  loop
    in file.read_line or_else (e) break end to line
    cat ("line: ", line) io.println
  end
  in file.close
  "data.txt" buf file.read_all_into or_fail
  cat ("all: ", buf contents) io.print
end
demo or_else (e) cat ("file error: ", e err_text) io.println end
"missing.txt" file.read_all or_else (e) cat ("missing.txt: ", e err_text) end io.println

Output

$ pnx 17-file.pnx
line: alpha
line: beta
all: alpha
beta
missing.txt: not_found

17.4 Channels and the host loop

(1) A channel is a line of byte messages, up to a set number of them. The host names a channel and registers it in a state as a module of that name (pinax_channel_register, library libpinax_host). The states that registered the same channel pass messages to each other. They share no memory: a message is copied in and copied out.

WordSignatureMeaning
send(msg str or fail)puts a message in; waits while the channel is full
receive(gives msg str or fail)takes the message that came first; waits while it is empty
close()no more messages go in

(2) send fails with err.full when the message is longer than the channel allows, and with err.cancelled once the channel is closed. receive fails with err.not_found on a channel that is closed and empty. Messages left in a closed channel are still taken.

(3) Only the task that called waits (14.2); the other tasks of the state go on. Only runs the host loop runs (pinax_loop_start) wait. In any other run, a send or receive that would have to wait ends the run with the fault PINAX_ERR_STATE.

(4) The host loop runs states on a set number of threads. A state runs on one thread at a time. A run whose budget (19.5) is used up goes to the back of the line, and a run that waits gives its thread up. While the host waits in pinax_loop_wait, when every run left waits for a channel and no host operation is outstanding, the loop ends all of them with PINAX_ERR_DEADLOCK.

17-channel.c

#include "pinax.h"
#include "pinax_loop.h"
#include <stdio.h>
#include <string.h>

/* One state sends the numbers 1 to 100 through the channel `jobs`; two others take them and
   add them up. The loop runs the three on two threads. */
static const char producer[] =
    "use jobs\nuse str\n"
    "word produce (n int gives r int)\n"
    "  1 to i\n"
    "  loop\n"
    "    i n gt until\n"
    "    i str.to_str jobs.send or_else (e) -1 return end\n"
    "    i 1 add to i\n"
    "  end\n"
    "  jobs.close\n"
    "  n\n"
    "end\n";
static const char consumer[] =
    "use jobs\nuse str\n"
    "word consume (n int gives r int)\n"
    "  0 to total\n"
    "  loop\n"
    "    jobs.receive or_else (e) \"\" end to m      rem not_found: closed and empty\n"
    "    m str.is_empty until\n"
    "    m str.to_int or_else (e) 0 end total add to total\n"
    "  end\n"
    "  total\n"
    "end\n";

typedef struct worker {
    unsigned char block[1 << 20];
    pinax_state *state;
    pinax_word word;
    int64_t in, out;
    pinax_args args;
    pinax_err outcome;
} worker;
static worker w[3];

static void done(void *user, pinax_state *state, pinax_err outcome) {
    (void)state;
    ((worker *)user)->outcome = outcome;
}

static int start(pinax_loop *loop, pinax_channel *jobs, worker *x, const char *source, const char *word) {
    pinax_config config = {.struct_size = sizeof config, .budget = 1000};
    if (pinax_open((pinax_mem){x->block, sizeof x->block}, &config, &x->state) != PINAX_OK ||
        pinax_channel_register(x->state, jobs) != PINAX_OK ||
        pinax_load(x->state, "main", (pinax_str){(const unsigned char *)source, strlen(source)}, PINAX_LOAD_CODE) ||
        pinax_find(x->state, word, "(n int gives r int)", 0, &x->word) != PINAX_OK)
        return 1;
    x->args = (pinax_args){.i = &x->in, .ri = &x->out};
    return pinax_loop_start(loop, x->state, x->word, &x->args, done, x) != PINAX_OK;
}

int main(void) {
    pinax_loop *loop;
    pinax_channel *jobs;
    if (pinax_loop_open(2, &loop) != PINAX_OK || pinax_channel_open(loop, "jobs", 4, 20, &jobs) != PINAX_OK)
        return 1;
    w[0].in = 100;
    if (start(loop, jobs, &w[1], consumer, "consume") || start(loop, jobs, &w[2], consumer, "consume") ||
        start(loop, jobs, &w[0], producer, "produce"))
        return 1;
    pinax_loop_wait(loop);
    printf("sent %lld, received %lld\n", (long long)w[0].out, (long long)(w[1].out + w[2].out));

    /* the channel is closed and empty now: one more receiver ends at once */
    w[1].in = 0;
    if (pinax_loop_start(loop, w[1].state, w[1].word, &w[1].args, done, &w[1]) != PINAX_OK)
        return 1;
    pinax_loop_wait(loop);
    printf("after close: %lld\n", (long long)w[1].out);

    /* a receiver on a channel nobody sends to: every run left waits, so the loop ends it */
    pinax_channel *idle;
    pinax_close(w[2].state);
    if (pinax_channel_open(loop, "jobs", 1, 20, &idle) != PINAX_OK || start(loop, idle, &w[2], consumer, "consume"))
        return 1;
    pinax_loop_wait(loop);
    printf("nobody sends: %s\n", w[2].outcome == PINAX_ERR_DEADLOCK ? "deadlock" : "?");
    pinax_loop_close(loop);
    for (int k = 0; k < 3; ++k)
        pinax_close(w[k].state);
    return 0;
}

Output

$ ./17-channel
sent 100, received 5050
after close: 0
nobody sends: deadlock
