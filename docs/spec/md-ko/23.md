# 부속서 C 크기의 한계 (규범)

(1) 적합한 처리기는 아래 “최소” 열의 크기를 받아들여야 한다. “이 구현” 열은 이 구현의 값이다. 용량의 기본값은 처리기마다 다르며(4 (5)), 호스트가 `pinax_config` 로 바꾼다.

| **항목** | **최소** | **이 구현** |
|---|---|---|
| 이름의 길이(바이트) | 31 | 31 |
| `ptn` 패턴의 길이(바이트) | 255 | 255 |
| `ptn` 의 갈무리 수 | 9 | 9 |
| `ptn` 낱말 한 번의 걸음 | 224 | 224 |
| `extern` 함수의 C 인자 | 8 | 8 |
| 호스트 낱말의 `str` 인자, 결과 | 8, 4 | 8, 4 |
| 호스트 모듈의 낱말 수(상태마다) | 64 | 64 |
| 핸들 타입의 수 | 16 | 16 |
| `dec(N)` 의 점 아래 자리 수(7.5) | 18 | 18 |
| 상태의 전역 수(모든 적재를 합해) | 1024 | 3839 |
| 낱말 하나의 `defer`(10.7) | 16 | 16 |
| 결함 뒤에 남는 지역 변수 | — | 16 개, 1 KB |
| 정수 칸 / 문자열 칸의 기본값 | — | 4096 / 1024 |
| 주 실행의 구역 기본값 | — | 65536 바이트 |
| 동시에 사는 핸들의 기본값 | — | 64 |
| 작업의 호출 깊이 / 구역의 기본값 | — | 16 / 1024 바이트 |
