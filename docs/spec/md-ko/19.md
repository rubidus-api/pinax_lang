# 19 호스트 인터페이스

(1) 호스트 인터페이스는 C 헤더 `pinax.h` 하나다. 그 헤더는 `<stddef.h>` 와 `<stdint.h>` 만 쓰고 C99, C23, C++ 컴파일러로 읽힌다. 이 절은 그 함수들이 무엇을 하는지 정한다. 함수마다 헤더의 주석이 더 자세하다.

(2) 한 상태는 한 번에 한 스레드만 쓴다. 상태 사이에는 나누는 것이 없다. 함수가 돌려주는 `pinax_str` 는 따로 적지 않으면 그 상태에 대한 다음 호출 전까지만 쓸 수 있다.

## 19.1 오류 번호

(1) 함수는 `pinax_err` 를 돌려준다. `PINAX_OK` 는 0 이다. 실패가 아닌 결과 셋이 있다: `PINAX_SUSPENDED`(예산이 다함, 19.5), `PINAX_WAITING`(모든 작업이 호스트를 기다림, 19.8), `PINAX_PENDING`(호스트 낱말이 나중에 끝남). `0x100` 부터는 스크립트의 결함과 실패(11.1 의 번호와 같다), `0x200` 부터는 인터페이스 자체의 실패다: `ARGUMENT`, `NO_ROOM`(덩이가 모자람), `SYNTAX`, `TYPE`(적재 거절), `NOT_FOUND`, `SIGNATURE`, `FORMAT`, `STATE`(지금 할 수 없는 호출).

(2) `pinax_error_text` 는 마지막 실패를 글로 준다. 결함이면 `모듈:줄: 이름` 꼴이다.

## 19.2 열기와 닫기

(1) `pinax_open(block, config, &state)` 은 덩이 `block` 안에 상태를 연다. `config` 의 0 인 칸은 처리기의 기본값이다: 뱅크의 칸 수, 주 실행의 구역 크기, 동시에 살 수 있는 핸들의 수, 실행 한 번의 명령 예산(0 이면 끝이 없다), 적재 진단을 받을 함수. 덩이가 모자라면 `PINAX_ERR_NO_ROOM` 이고, `pinax_needed` 가 넉넉했을 크기를 알려 준다.

(2) `config.hash_key` 는 찾아보기(8.10)가 쓰는 해시의 열쇠 16 바이트다. 밖에서 온 글을 키로 찾는 호스트는 무작위 열쇠를 준다. 모두 0 이면 정해진 열쇠를 쓴다.

(3) `pinax_close` 는 아직 열린 핸들을 닫는다(그 타입의 닫는 함수를 부른다). 덩이는 놓지 않는다 — 덩이는 호스트의 것이다.

## 19.3 호스트 낱말

(1) `pinax_register(state, 모듈, defs, count)` 는 호스트 함수를 모듈 하나의 낱말로 등록한다. `defs` 의 칸마다 이름, 서명 글(9.2 의 꼴, 예: `"(s str gives n int or fail)"`), 함수, 사용자 포인터, 깃발이 있다. 서명은 등록할 때 한 번 검사한다. 그 낱말을 쓰는 소스보다 먼저 등록한다.

(2) 호스트 함수는 `(call, user, args)` 를 받는다. 인자와 결과는 타입별 배열에 있다: 정수(그리고 `bool`, 문자, 핸들, `int` 위의 선언한 타입)는 `args->i[]` 와 `args->ri[]`, 문자열은 `args->s[]` 와 `args->rs[]`. 서명에 적힌 차례로, 타입마다 0 부터 센다. 정수 포인터는 상태의 칸을 바로 가리킨다.

(3) 함수가 `PINAX_OK` 가 아닌 값을 돌려주면, 서명에 `or fail` 이 있는 낱말은 그 번호로 실패하고(11.2) 없는 낱말은 결함으로 실행을 끝낸다.

(4) 문자열 결과는 `PINAX_WORD_KEEP_STR` 깃발이 없으면 부른 쪽의 구역으로 복사된다. 새 바이트를 만들 자리는 `pinax_call_alloc` 이 부른 쪽의 구역에서 준다. 서명에서 `buffer` 타입으로 받은 매개변수는 스크립트의 버퍼다. `pinax_call_buffer` 로 그 버퍼의 빈 자리를 얻고, 채운 바이트 수를 알린다.

`19-host-words.c`

```c
#include "pinax.h"
#include <stdio.h>
#include <string.h>

/* (s str gives r str): the result is written into the caller's region. */
static pinax_err shout(pinax_call *call, void *user, const pinax_args *args) {
    (void)user;
    pinax_mem room = pinax_call_alloc(call, args->s[0].len + 1);
    if (!room.ptr)
        return PINAX_ERR_FULL;                       /* no `or fail`: this is a fault */
    unsigned char *out = room.ptr;
    for (size_t k = 0; k < args->s[0].len; ++k) {
        unsigned char c = args->s[0].ptr[k];
        out[k] = c >= 'a' && c <= 'z' ? (unsigned char)(c - 32) : c;
    }
    out[args->s[0].len] = '!';
    args->rs[0] = (pinax_str){out, args->s[0].len + 1};
    return PINAX_OK;
}

/* (s str gives n int or fail): an outcome other than PINAX_OK is the word's failure. */
static pinax_err digits(pinax_call *call, void *user, const pinax_args *args) {
    (void)call; (void)user;
    int64_t n = 0;
    if (args->s[0].len == 0)
        return PINAX_ERR_FORMAT;
    for (size_t k = 0; k < args->s[0].len; ++k) {
        unsigned char c = args->s[0].ptr[k];
        if (c < '0' || c > '9')
            return PINAX_ERR_FORMAT;
        n = n * 10 + (c - '0');
    }
    args->ri[0] = n;
    return PINAX_OK;
}

/* (b buffer or fail): writes straight into a buffer the script declared. */
static pinax_err stamp(pinax_call *call, void *user, const pinax_args *args) {
    (void)user;
    pinax_mem room = pinax_call_buffer(call, args->i[0], 0);
    if (room.len < 5)
        return PINAX_ERR_FULL;
    memcpy(room.ptr, "[ok] ", 5);
    pinax_call_buffer(call, args->i[0], 5);
    return PINAX_OK;
}

int main(void) {
    static unsigned char block[1 << 20];
    pinax_config config = {.struct_size = sizeof config};
    pinax_state *st;
    if (pinax_open((pinax_mem){block, sizeof block}, &config, &st) != PINAX_OK)
        return 1;
    static const pinax_word_def words[] = {
        {"shout", "(s str gives r str)", shout, NULL, 0},
        {"digits", "(s str gives n int or fail)", digits, NULL, 0},
        {"stamp", "(b buffer or fail)", stamp, NULL, 0},
    };
    pinax_register(st, "app", words, 3);
    static const char source[] =
        "use app\n"
        "buffer line 32\n"
        "word demo (gives s str)\n"
        "  line clear\n"
        "  line app.stamp or_else (e) end\n"
        "  \"12x\" app.digits or_else (e) -1 end to n\n"
        "  cat (\"hello\" app.shout, \" \", \"42\" app.digits or_else (e) -1 end, \" \", n) line append or_else (e) end\n"
        "  line contents\n"
        "end\n";
    if (pinax_load(st, "main", (pinax_str){(const unsigned char *)source, sizeof source - 1}, PINAX_LOAD_CODE) != PINAX_OK)
        return 1;
    pinax_word w;
    pinax_str out;
    if (pinax_find(st, "demo", "(gives s str)", 0, &w) != PINAX_OK)
        return 1;
    pinax_run(st, w, &(pinax_args){.rs = &out});
    printf("%.*s\n", (int)out.len, (const char *)out.ptr);
    pinax_close(st);
    return 0;
}
```

*출력*

```text
$ ./19-host-words
[ok] HELLO! 42 -1
```

## 19.4 적재와 한 줄

(1) `pinax_load(state, 이름, 소스, 방식)` 은 소스를 적재한다(5.2). `이름` 은 모듈의 이름이다. 방식은 `PINAX_LOAD_CODE` 와 `PINAX_LOAD_DATA`(13.4)다. 거절하면 `PINAX_ERR_SYNTAX` 나 `PINAX_ERR_TYPE` 이고, 진단은 `config.diag` 에 (파일, 줄, 칸, 글)로 온다.

(2) `pinax_eval(state, 글)` 은 대화처럼 한 줄을 돌린다. 모든 줄은 한 모듈(세션)이다. 줄이 남긴 값은 `pinax_eval_count` 와 `pinax_eval_value` 로 읽는다.

## 19.5 찾기와 돌리기

(1) `pinax_find(state, 이름, 서명, 깃발, &word)` 은 낱말을 찾고 그 서명이 주어진 서명과 같은지 본다. 다르면 `PINAX_ERR_SIGNATURE` 다. 맨 이름은 처음 적재한 소스의 낱말이고, `모듈.낱말` 은 그 모듈의 낱말이다(내보내지 않았어도).

(2) `pinax_run(state, word, args)` 은 낱말을 돌린다. 예산이 다하면 `PINAX_SUSPENDED` 로 돌아오고, `pinax_resume` 이 멈춘 자리부터 잇는다. 예산은 결과를 바꾸지 않는다. 결함은 그 번호로 돌아오고, 상태는 다음 실행을 받는다.

(3) 멈춘 실행(`PINAX_SUSPENDED`, `PINAX_WAITING`)이 있는 동안 새 `pinax_run` 은 `PINAX_ERR_STATE` 다. 호스트는 그 실행을 끝까지 잇거나 `pinax_abort` 로 버린다.

(3a) `pinax_abort(state)` 는 멈춘 실행을 결함으로 끝난 것처럼 끝낸다: 그 실행이 연 핸들을 닫고, 작업을 비우고, 기다리던 표를 잊는다(그 표의 `pinax_complete` 는 `PINAX_ERR_NOT_FOUND`). 전역에 이미 넣은 값은 남는다. 멈춘 것이 적재 코드면 그 적재를 실패한 적재처럼 되돌린다. 그 뒤 상태는 다음 실행을 받는다. 멈춘 실행이 없으면 `PINAX_ERR_STATE` 다. 전역까지 실행 앞으로 되돌려야 하는 호스트는 실행 앞에 상(19.9)을 저장한다.

`19-run.c`

```c
#include "pinax.h"
#include <stdio.h>
#include <string.h>

static void load(pinax_state *st, const char *text) {
    if (pinax_load(st, "main", (pinax_str){(const unsigned char *)text, strlen(text)}, PINAX_LOAD_CODE) != PINAX_OK) {
        pinax_str why = pinax_error_text(st);
        printf("refused: %.*s\n", (int)why.len, (const char *)why.ptr);
    }
}

int main(void) {
    static unsigned char block[1 << 20];
    pinax_config config = {.struct_size = sizeof config, .budget = 1000};   /* instructions per run or resume */
    pinax_state *st;
    if (pinax_open((pinax_mem){block, sizeof block}, &config, &st) != PINAX_OK)
        return 1;
    load(st,
         "word total (n int gives r int) 0 to s  1 n 1 add range do (i int) s i add to s end each  s end\n"
         "word ratio (a int, b int gives r int) a 100 mul b div end\n");

    pinax_word w;
    /* the signature asked for must be the word's */
    printf("find with another signature: %s\n",
           pinax_find(st, "total", "(gives r int)", 0, &w) == PINAX_ERR_SIGNATURE ? "PINAX_ERR_SIGNATURE" : "?");
    pinax_find(st, "total", "(n int gives r int)", 0, &w);
    int64_t n = 100000, r = 0;
    pinax_args args = {.i = &n, .ri = &r};
    int resumes = 0;
    pinax_err err = pinax_run(st, w, &args);
    while (err == PINAX_SUSPENDED) {                 /* the budget ran out: go on where it stopped */
        ++resumes;
        err = pinax_resume(st, &args);
    }
    printf("total(100000) = %lld after %s resumes\n", (long long)r, resumes > 10 ? "many" : "few");

    /* a fault comes back as the error code, with its place in the error text */
    pinax_find(st, "ratio", "(a int, b int gives r int)", 0, &w);
    int64_t ab[2] = {3, 0};
    err = pinax_run(st, w, &(pinax_args){.i = ab, .ri = &r});
    pinax_str why = pinax_error_text(st);
    printf("ratio(3, 0): %s, \"%.*s\"\n", err == PINAX_ERR_DIV_ZERO ? "PINAX_ERR_DIV_ZERO" : "?", (int)why.len, (const char *)why.ptr);

    /* the state is still usable */
    ab[1] = 4;
    err = pinax_run(st, w, &(pinax_args){.i = ab, .ri = &r});
    printf("ratio(3, 4) = %lld\n", (long long)r);

    /* one line at a time, as a session does */
    const char *line = "6 7 mul \"done\"";
    if (pinax_eval(st, (pinax_str){(const unsigned char *)line, strlen(line)}) == PINAX_OK) {
        for (uint32_t k = 0; k < pinax_eval_count(st); ++k) {
            pinax_value v;
            pinax_eval_value(st, k, &v);
            if (v.kind == PINAX_VALUE_INT)
                printf("value %u: %lld (%.*s)\n", k, (long long)v.i, (int)v.type.len, (const char *)v.type.ptr);
            else
                printf("value %u: %.*s (%.*s)\n", k, (int)v.s.len, (const char *)v.s.ptr, (int)v.type.len, (const char *)v.type.ptr);
        }
    }
    pinax_close(st);
    return 0;
}
```

*출력*

```text
$ ./19-run
find with another signature: PINAX_ERR_SIGNATURE
total(100000) = 5000050000 after many resumes
ratio(3, 0): PINAX_ERR_DIV_ZERO, "main:2: div_zero"
ratio(3, 4) = 75
value 0: 42 (int)

```

(4) 호스트 낱말 안에서도 `pinax_run` 을 부를 수 있다. 그때는 `PINAX_FIND_NESTED` 깃발로 찾은 낱말만 돌리며, 양보할 수 있는 낱말(14.2)은 그 깃발로 찾지 못한다.

## 19.6 핸들

(1) `pinax_handle_type` 은 핸들 타입 하나를 이름과 닫는 함수로 만든다. 스크립트는 그 이름을 서명의 타입으로 쓴다. `pinax_handle_new` 는 C 포인터를 핸들로 만들고, `pinax_handle_get` 은 핸들의 포인터를 준다(돌려준 핸들이면 NULL). `pinax_handle_release` 는 핸들을 돌려준다.

(2) 핸들은 번호와 세대다(8.9 와 같다). 스크립트는 핸들로 주소를 얻지 못한다. 결함으로 끝난 실행이 연 핸들은 상태가 닫는 함수를 불러 닫는다.

`19-handles.c`

```c
#include "pinax.h"
#include <stdio.h>

typedef struct { int value; int open; } counter;
static counter pool_[4];
static uint32_t counter_type;

static void close_counter(void *object, void *user) {   /* called for handles the script never closed */
    (void)user;
    ((counter *)object)->open = 0;
    printf("closed by the state: counter at %d\n", ((counter *)object)->value);
}
static pinax_err c_new(pinax_call *call, void *user, const pinax_args *args) {
    (void)user;
    for (int k = 0; k < 4; ++k)
        if (!pool_[k].open) {
            pool_[k] = (counter){0, 1};
            pinax_handle h;
            pinax_err err = pinax_handle_new(pinax_call_state(call), counter_type, &pool_[k], &h);
            args->ri[0] = (int64_t)h;
            return err;
        }
    return PINAX_ERR_FULL;
}
static pinax_err c_bump(pinax_call *call, void *user, const pinax_args *args) {
    (void)user;
    counter *c = pinax_handle_get(pinax_call_state(call), counter_type, (pinax_handle)args->i[0]);
    if (!c)
        return PINAX_ERR_STALE;
    args->ri[0] = ++c->value;
    return PINAX_OK;
}
static pinax_err c_free(pinax_call *call, void *user, const pinax_args *args) {
    (void)user;
    counter *c = pinax_handle_get(pinax_call_state(call), counter_type, (pinax_handle)args->i[0]);
    if (c) {
        printf("freed by the script: counter at %d\n", c->value);
        c->open = 0;
    }
    return pinax_handle_release(pinax_call_state(call), counter_type, (pinax_handle)args->i[0]);
}

int main(void) {
    static unsigned char block[1 << 20];
    pinax_config config = {.struct_size = sizeof config};
    pinax_state *st;
    if (pinax_open((pinax_mem){block, sizeof block}, &config, &st) != PINAX_OK)
        return 1;
    pinax_handle_type(st, "counter", close_counter, NULL, &counter_type);
    static const pinax_word_def words[] = {
        {"new", "(gives owned counter or fail)", c_new, NULL, 0},
        {"bump", "(c counter gives n int)", c_bump, NULL, 0},
        {"free", "(c owned counter)", c_free, NULL, 0},
    };
    pinax_register(st, "ctr", words, 3);
    static const char source[] =
        "use ctr\n"
        "word twice (gives n int or fail)\n"
        "  ctr.new or_fail to c\n"
        "  c ctr.bump drop  c ctr.bump to n\n"
        "  c ctr.free\n"
        "  n\n"
        "end\n"
        "word broken (gives n int or fail)\n"
        "  ctr.new or_fail to c\n"
        "  c ctr.bump 0 div to n\n"            /* a fault while the counter is open */
        "  c ctr.free\n"
        "  n\n"
        "end\n";
    if (pinax_load(st, "main", (pinax_str){(const unsigned char *)source, sizeof source - 1}, PINAX_LOAD_CODE) != PINAX_OK)
        return 1;
    pinax_word w;
    int64_t n = 0;
    pinax_find(st, "twice", "(gives n int or fail)", 0, &w);
    pinax_run(st, w, &(pinax_args){.ri = &n});
    printf("twice = %lld\n", (long long)n);
    pinax_find(st, "broken", "(gives n int or fail)", 0, &w);
    pinax_err err = pinax_run(st, w, &(pinax_args){.ri = &n});
    printf("broken: %s\n", err == PINAX_ERR_DIV_ZERO ? "PINAX_ERR_DIV_ZERO" : "?");
    pinax_close(st);
    return 0;
}
```

*출력*

```text
$ ./19-handles

twice = 2
closed by the state: counter at 1
broken: PINAX_ERR_DIV_ZERO
```

## 19.7 묶기

(1) `pinax_bind(state, 전역, 메모리, 바이트)` 는 `bound` 로 선언한 전역(8.12)의 저장소를 호스트 메모리로 바꾼다. 크기는 선언과 같아야 한다. 스크립트와 호스트는 복사 없이 같은 바이트를 읽고 쓴다. `pinax_global_find` 는 선언한 전역의 자리와 크기를 알려 준다.

`19-bind.c`

```c
#include "pinax.h"
#include <stdio.h>

int main(void) {
    static unsigned char block[1 << 20];
    pinax_config config = {.struct_size = sizeof config};
    pinax_state *st;
    if (pinax_open((pinax_mem){block, sizeof block}, &config, &st) != PINAX_OK)
        return 1;
    static const char source[] =
        "bound array samples int 5\n"
        "bound global scale int\n"
        "word scaled_sum (gives n int) samples sum scale mul end\n"
        "word clear_first () 0 0 set samples end\n";
    if (pinax_load(st, "main", (pinax_str){(const unsigned char *)source, sizeof source - 1}, PINAX_LOAD_CODE) != PINAX_OK)
        return 1;
    static int64_t samples[5] = {1, 2, 3, 4, 5};    /* host memory the script reads and writes in place */
    static int64_t scale = 10;
    pinax_bind(st, "samples", samples, sizeof samples);
    pinax_bind(st, "scale", &scale, sizeof scale);
    pinax_word w;
    int64_t n = 0;
    pinax_find(st, "scaled_sum", "(gives n int)", 0, &w);
    pinax_run(st, w, &(pinax_args){.ri = &n});
    printf("scaled_sum = %lld\n", (long long)n);
    samples[4] = 105;                                /* the host changes it; no copy to refresh */
    pinax_run(st, w, &(pinax_args){.ri = &n});
    printf("after the host wrote samples[4]: %lld\n", (long long)n);
    pinax_find(st, "clear_first", "()", 0, &w);
    pinax_run(st, w, NULL);
    printf("after the script wrote cell 0: samples[0] = %lld\n", (long long)samples[0]);
    pinax_close(st);
    return 0;
}
```

```text
$ ./19-bind

after the host wrote samples[4]: 1150
after the script wrote cell 0: samples[0] = 0
```

(1a) `pinax_share(state, global, source, from)` 은 `state` 에서 `shared` 로 선언한 전역(8.13)에 `source` 의 전역 `from` 의 저장소를 준다. 복사하지 않는다. 종류, 타입, 용량이 같아야 하며, 아니면 `PINAX_ERR_SIGNATURE` 다. 찾아보기는 해시 열쇠(19.2)도 같아야 하고, 그 표를 같은 `source` 에서 먼저 받아야 한다. 목록은 그때의 길이를 쓴다. 표를 다시 받으면 그 표의 찾아보기도 다시 준다.

(1b) 저장소를 빌려준 `source` 는 얼어붙는다: 그 뒤의 `pinax_run`, `pinax_load`, `pinax_eval`, `pinax_bind` 는 `PINAX_ERR_STATE` 다. 그래서 바이트가 바뀌지 않고, 여러 스레드의 상태가 한꺼번에 읽어도 된다. `source` 는 빌린 상태들이 쓰는 동안 열려 있어야 한다. 공유 전역을 다 받기 전에는 실행이 `PINAX_ERR_NOT_FOUND` 로 거절된다. 상을 열거나 복제한 뒤에는 다시 준다(19.9).

`19-share.c`

```c
#include "pinax.h"
#include <stdio.h>
#include <string.h>

/* One state holds the data; two others read it in place. Nothing is copied. */
static const char data[] =
    "record city\n  name str(12)\n  people int\nend\n"
    "list cities city 8\n"
    "index by_name cities city.name\n"
    "row cities (\"Seoul\", 9411)\n"
    "row cities (\"Busan\", 3317)\n"
    "row cities (\"Incheon\", 3001)\n";
static const char reader[] =
    "record city\n  name str(12)\n  people int\nend\n"
    "shared list cities city 8\n"
    "shared index by_name cities city.name\n"
    "word people_of (name str gives n int or fail) name by_name lookup or_fail city.people end\n"
    "word total (gives n int)\n"
    "  0 to t  0 to i\n"
    "  loop i cities len lt while  t i cities idx city.people add to t  i 1 add to i end\n"
    "  t\n"
    "end\n";

static pinax_state *open_in(unsigned char *block, size_t bytes) {
    pinax_config config = {.struct_size = sizeof config};
    pinax_state *st;
    return pinax_open((pinax_mem){block, bytes}, &config, &st) == PINAX_OK ? st : NULL;
}

static int64_t call(pinax_state *st, const char *word, const char *signature, const char *name, pinax_err *err) {
    pinax_word w;
    int64_t out = 0;
    pinax_str in = {(const unsigned char *)name, name ? strlen(name) : 0};
    pinax_args args = {.s = &in, .ri = &out};
    *err = pinax_find(st, word, signature, 0, &w);
    if (*err == PINAX_OK)
        *err = pinax_run(st, w, &args);
    return out;
}

int main(void) {
    static unsigned char blocks[3][1024 * 1024];
    pinax_state *source = open_in(blocks[0], sizeof blocks[0]);
    pinax_state *a = open_in(blocks[1], sizeof blocks[1]), *b = open_in(blocks[2], sizeof blocks[2]);
    if (!source || !a || !b || pinax_load(source, "data", (pinax_str){(const unsigned char *)data, strlen(data)},
                                          PINAX_LOAD_DATA) != PINAX_OK)
        return 1;
    pinax_err err;
    pinax_state *readers[2] = {a, b};
    for (int k = 0; k < 2; ++k) {
        if (pinax_load(readers[k], "main", (pinax_str){(const unsigned char *)reader, strlen(reader)},
                       PINAX_LOAD_CODE) != PINAX_OK)
            return 1;
    }
    call(a, "total", "(gives n int)", NULL, &err);
    printf("before sharing: %#x (not found)\n", (unsigned)err);

    for (int k = 0; k < 2; ++k) /* the table first, then its index */
        if (pinax_share(readers[k], "cities", source, "cities") != PINAX_OK ||
            pinax_share(readers[k], "by_name", source, "by_name") != PINAX_OK)
            return 1;
    printf("a: Busan has %lld\n", (long long)call(a, "people_of", "(name str gives n int or fail)", "Busan", &err));
    printf("b: total %lld\n", (long long)call(b, "total", "(gives n int)", NULL, &err));

    pinax_global mine, theirs;
    pinax_global_find(source, "cities", &theirs);
    pinax_global_find(b, "cities", &mine);
    printf("same bytes: %s\n", mine.ptr == theirs.ptr ? "yes" : "no");
    err = pinax_load(source, "more", (pinax_str){(const unsigned char *)"global x int\n", 13}, PINAX_LOAD_CODE);
    printf("the source loads again: %#x (state)\n", (unsigned)err);
    pinax_close(a);
    pinax_close(b);
    pinax_close(source);
    return 0;
}
```

*출력*

```text
$ ./19-share
before sharing: 0x204 (not found)
a: Busan has 3317
b: total 15729
same bytes: yes
the source loads again: 0x207 (state)
```

(2) `pinax_global_find` 가 주는 `number` 는 모음 매개변수(9.9)가 있는 낱말이 그 인자로 받는 것이다. `i` 에 넣는 정수다. 종류나 원소 크기가 다른 모음, 또는 없는 전역의 번호는 낱말이 그것을 쓰는 자리에서 결함 `PINAX_ERR_STATE` 다.

## 19.8 나중에 끝나는 호스트 낱말

(1) `PINAX_WORD_AWAITABLE` 로 등록한 호스트 낱말은 일을 시작하고 `pinax_call_pending` 으로 표를 받은 뒤 `PINAX_PENDING` 을 돌려줄 수 있다. 부른 작업은 기다리고 다른 작업이 돈다. 돌 것이 없으면 `pinax_run` 이나 `pinax_resume` 이 `PINAX_WAITING` 을 돌려준다. 호스트는 `pinax_complete(state, 표, 결과, 값)` 로 일을 끝내고 `pinax_resume` 을 부른다.

`19-await.c`

```c
#include "pinax.h"
#include <stdio.h>

/* A host word that finishes later: it starts the work, keeps a token and returns PINAX_PENDING. */
static pinax_token waiting[4];
static int64_t asked[4];
static int n_waiting;
static pinax_err fetch(pinax_call *call, void *user, const pinax_args *args) {
    (void)user;
    asked[n_waiting] = args->i[0];
    waiting[n_waiting++] = pinax_call_pending(call);
    return PINAX_PENDING;
}

int main(void) {
    static unsigned char block[1 << 20];
    pinax_config config = {.struct_size = sizeof config};
    pinax_state *st;
    if (pinax_open((pinax_mem){block, sizeof block}, &config, &st) != PINAX_OK)
        return 1;
    static const pinax_word_def words[] = {{"fetch", "(n int gives r int or fail)", fetch, NULL, PINAX_WORD_AWAITABLE}};
    pinax_register(st, "net", words, 1);
    static const char source[] =
        "use net\n"
        "tasks workers 2\n"
        "list got int 4\n"
        "word both (gives r int)\n"
        "  do 1 net.fetch or_else (e) -1 end got push or_else (e) end end workers spawn or_else (e) 0 return end drop\n"
        "  do 2 net.fetch or_else (e) -1 end got push or_else (e) end end workers spawn or_else (e) 0 return end drop\n"
        "  workers run_all\n"
        "  got sum\n"
        "end\n";
    if (pinax_load(st, "main", (pinax_str){(const unsigned char *)source, sizeof source - 1}, PINAX_LOAD_CODE) != PINAX_OK)
        return 1;
    pinax_word w;
    int64_t r = 0;
    pinax_args args = {.ri = &r};
    pinax_find(st, "both", "(gives r int)", 0, &w);
    pinax_err err = pinax_run(st, w, &args);
    printf("run: %s, %d operations started\n", err == PINAX_WAITING ? "PINAX_WAITING" : "?", n_waiting);
    /* the host finishes them in its own time, here the second first */
    for (int k = n_waiting - 1; k >= 0; --k) {
        int64_t result = asked[k] * 100;
        pinax_complete(st, waiting[k], PINAX_OK, &(pinax_args){.ri = &result});
    }
    err = pinax_resume(st, &args);
    printf("resume: %s, both = %lld\n", err == PINAX_OK ? "PINAX_OK" : "?", (long long)r);
    pinax_close(st);
    return 0;
}
```

*출력*

```text
$ ./19-await
run: PINAX_WAITING, 2 operations started
resume: PINAX_OK, both = 300
```

(2) 호스트 루프(17.4)가 돌리는 상태에서는 호스트 낱말이 `pinax_call_pending` 대신 `pinax_loop_pending` 으로 표를 받고, 어느 스레드에서든 `pinax_loop_complete` 로 일을 끝낸다. 루프는 그 상태의 스레드에서 `pinax_complete` 를 부르고 실행을 잇는다.

## 19.9 상과 복제

(1) **상**(image)은 상태 전체다: 코드, 선언, 전역, 칸, 구역, 멈춘 실행과 작업. `pinax_image_save` 가 쓰고 `pinax_image_open` 이 연다. 상이 덩이의 처음에 놓여 있으면 복사 없이 그 자리에서 연다. 다른 형식이나 다른 빌드의 메모리 배치로 만든 상은 `PINAX_ERR_FORMAT` 이다.

(2) 연 상태에는 호스트 낱말, 핸들 타입, `extern` 함수를 이름으로 다시 준다. 다 주기 전에는 실행이 `PINAX_ERR_NOT_FOUND` 로 거절된다. 핸들은 닫힌 채(닫는 함수 없이), 묶은 전역은 자기 저장소로 돌아와 있다. `pinax_clone` 은 한 번에 저장하고 다른 덩이에서 연다.

`19-image.c`

```c
#include "pinax.h"
#include <stdio.h>
#include <stdlib.h>

static pinax_err twice(pinax_call *call, void *user, const pinax_args *args) {
    (void)call; (void)user;
    args->ri[0] = args->i[0] * 2;
    return PINAX_OK;
}
static const pinax_word_def words[] = {{"twice", "(n int gives r int)", twice, NULL, 0}};

static int64_t call_next(pinax_state *st) {
    pinax_word w;
    int64_t r = 0;
    if (pinax_find(st, "next", "(gives r int)", 0, &w) != PINAX_OK)
        return -1;
    pinax_err err = pinax_run(st, w, &(pinax_args){.ri = &r});
    return err == PINAX_OK ? r : -(int64_t)err;
}

int main(void) {
    static _Alignas(16) unsigned char a[1 << 20], b[1 << 20], c[1 << 20];
    pinax_config config = {.struct_size = sizeof config};
    pinax_state *st;
    if (pinax_open((pinax_mem){a, sizeof a}, &config, &st) != PINAX_OK)
        return 1;
    pinax_register(st, "host", words, 1);
    static const char source[] =
        "use host\n"
        "global calls int\n"
        "word next (gives r int) calls 1 add set calls  calls host.twice end\n";
    if (pinax_load(st, "main", (pinax_str){(const unsigned char *)source, sizeof source - 1}, PINAX_LOAD_CODE) != PINAX_OK)
        return 1;
    call_next(st);
    printf("in the first state: %lld\n", (long long)call_next(st));

    /* save the whole state: code, globals, everything */
    size_t size = pinax_image_size(st), written = 0;
    unsigned char *image = malloc(size);
    pinax_image_save(st, (pinax_mem){image, size}, &written);

    /* open it in another block; host words are given again by name */
    pinax_state *copy;
    if (pinax_image_open((pinax_mem){b, sizeof b}, (pinax_str){image, written}, &config, &copy) != PINAX_OK)
        return 1;
    printf("before the host word is given again: %s\n", call_next(copy) == -PINAX_ERR_NOT_FOUND ? "PINAX_ERR_NOT_FOUND" : "?");
    pinax_register(copy, "host", words, 1);
    printf("the copy goes on: %lld\n", (long long)call_next(copy));
    printf("the first state is its own: %lld\n", (long long)call_next(st));

    /* a clone is the same in one call */
    pinax_state *twin;
    if (pinax_clone(copy, (pinax_mem){c, sizeof c}, &twin) != PINAX_OK)
        return 1;
    pinax_register(twin, "host", words, 1);
    printf("the clone of the copy: %lld\n", (long long)call_next(twin));
    free(image);
    pinax_close(twin);
    pinax_close(copy);
    pinax_close(st);
    return 0;
}
```

*출력*

```text
$ ./19-image
in the first state: 4
before the host word is given again: PINAX_ERR_NOT_FOUND
the copy goes on: 6
the first state is its own: 6
the clone of the copy: 8
```
