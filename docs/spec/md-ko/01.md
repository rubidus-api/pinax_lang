# 1 범위

(1) 이 문서는 끼워 쓰는(embeddable) 스크립트 언어 Pinax 를 정한다. 무엇이 Pinax 프로그램으로 적합한지, 적합한 프로그램이 돌 때 무엇을 하는지, 적합하지 않은 프로그램을 처리기가 어떻게 거절하는지, 그리고 C 프로그램이 처리기를 어떻게 부르는지를 정한다.

(2) 이 문서가 정하는 것은 다음이다.소스의 글자와 토큰(6절), 타입과 값(7절), 선언(8절), 낱말과 스택(9절), 제어(10절);실패와 결함(11절), 메모리(12절), 모듈(13절), 작업(14절);핵 낱말(15절), 표준 모듈(16절), 호스트 모듈(17절), C 함수 부르기(18절);호스트 인터페이스(19절)와 명령 `pnx`(20절);부속서: 문법 전체(A), 진단 목록(B), 크기의 한계(C), 이 판에 없는 것(D).

(3) 이 문서가 정하지 않는 것은 다음이다.처리기가 소스를 어떤 명령으로 옮기고 어떻게 실행하는가. 바이트코드의 모양과 실행 방식은 처리기의 일이다. 다만 19절이 정하는 호스트 인터페이스로 관찰할 수 있는 것은 이 문서가 정한다.실행 속도와 메모리 사용량의 수치.이 판에 없는 기능(부속서 D). 그것들은 이름만 남아 있거나(예약 낱말) 쓰면 거절된다.

(4) 이 문서는 처리기 하나를 기준으로 쓴 것이 아니다. 그러나 이 문서의 모든 예제는 같은 저장소의 구현(`pnx`, `libpinax`)으로 실제로 돌렸고, 실린 출력은 그때 받은 그대로다. 예제와 본문이 어긋나면 본문이 이긴다.

> **참고**
>
> Pinax 는 고정된 메모리 한 덩이 안에서 도는 스크립트 언어다. 쓰레기 수거기(garbage collector), 힙 할당, 포인터, 객체, 동적 타입, 예외가 없다. 표면은 타입이 있는 Forth 다 — 낱말 사이는 스택으로 값을 넘기고, 한 낱말 안에서는 이름을 쓴다. 이 문서의 나머지는 그 한 문장을 하나하나 풀어 정한 것이다.
