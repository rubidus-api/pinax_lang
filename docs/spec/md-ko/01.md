# 1 범위

(1) 이 문서는 **처리기**(processor) 를 정한다.

#### 제약

(2) 문자열을 받는 낱말에 정수를 줄 수 없다.

`hello.pnx`

```pinax
use io
"hello, world" io.println
```

*출력*

```text
$ pnx hello.pnx
hello, world
```

`hello-refused.pnx`

```pinax
use io
42 io.println
```

*거절*

```text
$ pnx hello-refused.pnx
hello-refused.pnx:2:4: an argument has another type than the word's signature asks for
```

> **문답**
>
> 물음. 무엇인가?
>   
>
> 답. 이것이다.

| **조건** | **메시지** |
|---|---|
| 타입이 다르다 | `an argument has another type` |
