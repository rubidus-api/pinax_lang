# 10 제어

#### 구문

```ebnf
control = "if" { body } [ "else" { body } ] "end"
        | "loop" [ "(" NAME ")" ] { body } "end"
        | "case" { branch } [ "otherwise" { body } "end" ] "end" ;
branch  = values "of" { body } "end" ;
values  = case-value | "(" case-value { "," case-value } ")" ;
leave   = ( "while" | "until" | "break" ) [ "(" NAME ")" ] | "return" ;
block   = "do" [ "(" effect ")" ] { body } "end" ;
```

(1) `end` 는 가장 안쪽에 열린 것 하나를 닫는다. 여는 낱말은 `word` `test` `record` `do` `if` `loop` `case` `of` `otherwise` `or_else` 다.

(2) 처리기는 적재 때 모든 갈래의 스택을 견준다. 갈래가 다시 만나는 자리에서 스택은 어느 갈래로 왔든 같아야 한다. **떠나는 갈래**(leaving branch) — `return` `fail` `break` 로 끝나거나 끝나지 않는 루프로 끝나는 갈래 — 는 견주지 않는다.

## 10.1 갈림

(1) `조건 if 몸 end` 는 맨 위의 `bool` 을 내려 참이면 몸을 돈다. `조건 if 몸 else 몸 end` 는 거짓이면 `else` 의 몸을 돈다.

(2) `else` 가 없는 `if` 의 몸은 스택을 들어올 때와 같게 둬야 한다. `else` 가 있으면 두 몸은 같은 스택을 남겨야 한다.

`10-if.pnx`

```pinax
use io
word sign (n int gives str) n 0 lt if "negative" else n 0 eq if "zero" else "positive" end end end
-5 sign io.println
0 sign io.println
word warn (n int) n 100 gt if "big" io.println end end      rem no else: the branch leaves the stack as it was
500 warn
```

*출력*

```text
$ pnx 10-if.pnx
negative
zero
big
```

#### 제약

(3) 두 갈래가 남기는 스택이 다르면 거절된다.

`10-if-unequal.pnx`

```pinax
word f (n int gives int) n 0 lt if 1 2 else 3 end end
```

*거절*

```text
$ pnx 10-if-unequal.pnx
10-if-unequal.pnx:1:47: the two branches of this if leave different stacks
```

## 10.2 루프

(1) `loop 몸 end` 는 몸을 되풀이한다. 몸 안에서 다음 낱말이 루프를 떠난다.

- `조건 while` — 조건이 거짓이면 떠난다.
- `조건 until` — 조건이 참이면 떠난다.
- `break` — 조건 없이 떠난다.

셋은 몇 번이든 쓸 수 있고, 루프의 몸에 바로 쓰거나 그 안의 갈래(`if` `else` `case` `or_else`) 안에 쓴다. 가장 안쪽 루프를 떠난다.

(2) 한 바퀴는 스택을 들어올 때와 같게 둬야 한다. 떠나는 자리마다 스택은 루프에 들어올 때와 같아야 한다. 루프의 결과가 필요하면 지역 변수에 둔다.

`10-loop.pnx`

```pinax
use io
use str
word digits (n int gives int)            rem how many decimal digits
  1 to count_
  loop
    n 10 div to n
    n 0 eq until
    count_ 1 add to count_
  end
  count_
end
12345 digits str.to_str io.println
word first_square_over (limit int gives int)
  1 to i
  loop
    i i mul limit gt if break end
    i 1 add to i
  end
  i
end
50 first_square_over str.to_str io.println
```

*출력*

```text
$ pnx 10-loop.pnx
5
8
```

(3) `loop (이름)` 은 루프에 이름을 붙인다. `while (이름)` `until (이름)` `break (이름)` 은 그 이름의 루프까지 한 번에 떠난다. 이름은 그 루프의 몸 안에서만 보이고 값이 아니다. 가림 금지(9.5)를 따른다.

`10-loop-named.pnx`

```pinax
use io
use str
word find_pair (target int gives str)      rem the first a, b in 1..9 with a*b = target
  1 to a
  0 to b
  loop (rows)
    1 to b
    loop
      a b mul target eq until (rows)       rem leaves both loops at once
      b 1 add to b
      b 9 gt until
    end
    a 1 add to a
    a 9 gt if "none" return end
  end
  cat (a, " x ", b)
end
42 find_pair io.println
```

*출력*

```text
$ pnx 10-loop-named.pnx
6 x 7
```

(4) 자기를 떠나는 `while` `until` `break` 가 하나도 없는 루프는 끝나지 않는 루프다. 끝나지 않는 루프는 떠나는 갈래로 센다. 그래서 그 뒤에 결과를 적지 않아도 낱말의 서명이 맞는다. 안쪽 루프의 `until` 은 바깥 루프를 떠나는 것으로 세지 않지만, 안쪽에 쓴 `until (바깥 이름)` 은 센다.

`10-forever.pnx`

```pinax
use io
use str
word first_multiple (n int, k int gives int)     rem a loop with no exit counts as leaving
  loop
    n k mod 0 eq if n return end
    n 1 add to n
  end
end
100 7 first_multiple str.to_str io.println
```

*출력*

```text
$ pnx 10-forever.pnx
105
```

#### 제약

(5) 한 바퀴가 스택을 바꾸면 거절된다.

`10-loop-net.pnx`

```pinax
word f (gives int)
  0
  loop
    1 add
    dup 10 gt until
    1
  end
end
```

*거절*

```text
$ pnx 10-loop-net.pnx
10-loop-net.pnx:7:3: one turn of a loop must leave the stack as it found it
```

(6) `while` `until` `break` 를 루프 밖에 쓰면 거절된다. `do` 블록 안에서 바깥 루프를 떠나지도 못한다.

`10-while-outside.pnx`

```pinax
word f (n int) n 0 gt while end
```

*거절*

```text
$ pnx 10-while-outside.pnx
10-while-outside.pnx:1:23: while, until and break belong inside a loop
```

(7) 떠나는 낱말(`return` `fail` `break`)이나 끝나지 않는 루프 바로 뒤에 같은 갈래의 코드가 더 있으면 닿지 않는 코드로 거절된다.

`10-unreachable.pnx`

```pinax
word f (n int gives int) n return 1 add end
```

*거절*

```text
$ pnx 10-unreachable.pnx
10-unreachable.pnx:1:35: this code cannot be reached: the code before it always leaves
```

## 10.3 고르기

(1) `값 case 가지… end` 는 맨 위의 `int` 나 `str` 를 내려 가지의 값과 견주고, 같은 첫 가지의 몸을 돈다. 가지의 값은 리터럴이나 이 소스의 `const` 다. 한 가지에 값이 여럿이면 괄호에 쉼표로 적는다. 맞는 가지가 없으면 `otherwise` 의 몸을 돈다. 가지마다 같은 스택을 남겨야 한다.

`10-case.pnx`

```pinax
use io
const quit_code 9
word describe (cmd str gives str)
  cmd case
    "add" of "adds a line" end
    ("rm", "del") of "deletes a line" end
    otherwise "unknown command" end
  end
end
word level (n int gives str)
  n case
    0 of "off" end
    1 of "low" end
    quit_code of "quit" end
    otherwise "high" end
  end
end
"del" describe io.println
"mv" describe io.println
9 level io.println
```

*출력*

```text
$ pnx 10-case.pnx
deletes a line
unknown command
quit
```

#### 제약

(2) 같은 값이 두 가지에 있으면 거절된다.

`10-case-twice.pnx`

```pinax
word f (n int gives int) n case 1 of 10 end 1 of 20 end otherwise 0 end end end
```

*거절*

```text
$ pnx 10-case-twice.pnx
10-case-twice.pnx:1:45: this value is already in an earlier branch of the case
```

(3) 모듈의 상수(`json.key`, `err.full` 같은 경로)는 가지의 값이 되지 못한다. 그런 값은 `eq` 로 견준다.

`10-case-path.pnx`

```pinax
use json
word f (k int gives bool) k case json.key of true end otherwise false end end end
```

*거절*

```text
$ pnx 10-case-path.pnx
10-case-path.pnx:2:34: a case value is a literal or the name of a const
```

#### 결함

(4) `otherwise` 가 없고 맞는 가지도 없으면 결함 `range` 다.

`10-case-nomatch.pnx`

```pinax
use io
word f (n int gives str) n case 1 of "one" end 2 of "two" end end end
2 f io.println
3 f io.println
```

*결함으로 멈춤*

```text
$ pnx 10-case-nomatch.pnx
two
10-case-nomatch.pnx:2: index out of range
  n int = 3
```

## 10.4 돌아가기

(1) `return` 은 낱말을 그 자리에서 끝낸다. 그 자리의 스택은 결과와 맞아야 한다(9.2 (4)).

#### 제약

(2) `return` 은 정의(낱말, 값이 되는 블록, 시험) 안에서만 쓴다. 정의 밖의 코드에 쓰면 거절된다.

`10-return-outside.pnx`

```pinax
use io
"start" io.println
return
```

*거절*

```text
$ pnx 10-return-outside.pnx
10-return-outside.pnx:3:1: return belongs inside a definition
```

## 10.5 블록

(1) `do … end` 는 **블록**(block)이다. 블록은 두 가지로 쓰인다. 모양은 같고, 블록을 받는 쪽이 가른다.

- **끼워 넣는 블록** (inline block) — 조합 낱말(10.6)에 바로 준 블록. 그 자리에 펼쳐진다. 그래서 바깥의 지역 변수를 읽고 쓸 수 있고, 안에서 `return` 하면 바깥 낱말을 떠난다.
- **값이 되는 블록** (block value) — 지역 변수에 넣거나, 블록을 받는 매개변수( `word (서명)` 타입)에 주는 블록. 이름 없는 낱말 하나가 되며 `call` 로 부른다. 바깥의 지역 변수를 보지 못한다(붙잡지 않는다). 전역은 본다.

(2) `do` 바로 뒤에 서명을 쓸 수 있고, 그 이름들은 낱말 정의와 같이 블록의 지역 변수가 된다. 받는 쪽이 효과를 정해 주면 서명을 줄일 수 있다.

`10-inline-locals.pnx`

```pinax
use io
use str
word total_over (limit int gives int)
  0 to acc
  1 10 range do (i int) i limit gt if acc i add to acc end end each   rem the block sees acc and limit
  acc
end
5 total_over str.to_str io.println
```

*출력*

```text
$ pnx 10-inline-locals.pnx
30
```

`10-value-block.pnx`

```pinax
use io
use str
word twice (n int, f word (int gives int) gives int) n f call f call end
5 do (x int gives int) x 3 mul end twice str.to_str io.println
word add_one (int gives int) 1 add end
word demo (gives int)
  do (x int gives int) x add_one end to step     rem a block value in a local
  41 step call
end
demo str.to_str io.println
```

*출력*

```text
$ pnx 10-value-block.pnx
45
42
```

#### 제약

(3) 값이 되는 블록이 바깥의 지역 변수를 쓰면 거절된다(그 이름은 블록 안에 선언돼 있지 않다).

`10-value-block-outer.pnx`

```pinax
word twice (n int, f word (int gives int) gives int) n f call f call end
word scale (k int gives int) 5 do (x int gives int) x k mul end twice end
```

*거절*

```text
$ pnx 10-value-block-outer.pnx
10-value-block-outer.pnx:2:55: this name is not declared before this place
```

(4) 루프로 펼쳐지는 블록(`each` `times` 등)은 스택을 들어올 때와 같게 둬야 한다.

`10-block-net.pnx`

```pinax
array xs int 3
word f (gives int) 0 xs do (x int) x end each end
```

*거절*

```text
$ pnx 10-block-net.pnx
10-block-net.pnx:2:38: this block must leave the stack as it found it
```

## 10.6 줄기와 조합 낱말

(1) **줄기**(stem)는 차례로 값을 내는 것이다. 줄기는 값이 아니어서 지역 변수에 넣지 못하고, 바로 뒤의 조합 낱말이 받아야 한다. 둘이 합쳐 루프 하나가 된다. 줄기를 내는 것은 다음과 같다.

| **줄기** | **원소** |
|---|---|
| 배열, 목록의 이름 | 칸의 값(레코드면 줄). 목록은 길이까지. 큐, 풀, 버퍼, 찾아보기는 줄기가 아니다 |
| `lo hi range` | `lo` 부터 `hi` 앞까지의 `int` |
| `s sep str.split`, `s str.lines`, `s str.words`, `s str.chars` | `str` 뷰(16.1). `chars` 는 UTF-8 글자 하나씩 |
| `s str.bytes` | `int`: 바이트(16.1) |
| `s pat ptn.matches`, `s re rex.matches`, `s re rex.split` | 맞은 부분(16.6, 16.7) |
| `s csv.fields` | 필드(16.9) |

(2) 조합 낱말은 다음과 같다. “블록” 열은 블록이 받고 주는 것이다.

| **낱말** | **블록** | **결과** |
|---|---|---|
| `each` | `(T)` | 없음 |
| `each_index` | `(T, i int)` | 없음 |
| `fold` | `(acc U, T gives U)` | `U`. 첫 값을 줄기 앞에 둔다: `0 xs do … end fold` |
| `count` | `(T gives bool)` | `int` |
| `any` `all` | `(T gives bool)` | `bool`. 답이 정해지면 일찍 끝난다 |
| `first` | `(T gives bool)` | `T or fail`. 없으면 `err.not_found` |
| `sum` | 없음 | `int`. 넘치면 결함 `overflow` |
| `minimum` `maximum` | 없음 | `int or fail`. 빈 줄기면 `err.not_found` |
| `map_into` | `(T gives U)` | 뒤에 목적지. `or fail` |
| `filter_into` | `(T gives bool)` | 뒤에 목적지. `or fail` |
| `n times` | `()` | 없음. 줄기 없이 `n` 번 |

`10-combinators.pnx`

```pinax
use io
use str
array scores int 6
assign scores (72, 95, 88, 61, 90, 79)
scores sum str.to_str io.println
scores do (s int gives bool) s 90 ge end count str.to_str io.println
scores do (s int gives bool) s 60 lt end any if "someone failed" else "all passed" end io.println
0 scores do (acc int, s int gives int) acc s max end fold str.to_str io.println
scores do (s int, i int) i 2 lt if cat ("#", i, " ", s) io.println end end each_index
1 5 range do (i int) i str.to_str io.print end each
"" io.println
3 do "x" io.print end times
"" io.println
```

*출력*

```text
$ pnx 10-combinators.pnx
485
2
all passed
95
#0 72
#1 95
1234
xxx
```

`10-first.pnx`

```pinax
use io
use str
array xs int 5
assign xs (3, 8, 12, 5, 20)
xs do (x int gives bool) x 10 gt end first or_else (e) -1 end str.to_str io.println
xs do (x int gives bool) x 100 gt end first or_else (e) -1 end str.to_str io.println
xs minimum or_else (e) 0 end str.to_str io.println
```

*출력*

```text
$ pnx 10-first.pnx
12
-1
3
```

(3) `map_into` 와 `filter_into` 는 새 저장소를 만들지 않고 목적지에 쓴다. 목적지가 목록이면 끝에 `push` 하고 아무것도 주지 않는다. 목적지가 배열이면 0 번 칸부터 쓰고 쓴 칸의 수를 준다(`gives n int orfail`). 목적지가 차면 `err.full` 로 실패하고, 그때까지 쓴 것은 남는다.

`10-map-into.pnx`

```pinax
use io
use str
array xs int 4
assign xs (1, 2, 3, 4)
list squares int 4
array evens int 4
word go (or fail)
  xs do (x int gives int) x x mul end squares map_into or_fail
  xs do (x int gives bool) x 2 mod 0 eq end evens filter_into or_fail to n
  cat ("squares ", 3 squares idx, ", evens written ", n) io.println
end
go or_else (e) e err_text io.println end
```

*출력*

```text
$ pnx 10-map-into.pnx
squares 16, evens written 2
```

#### 진단

| **조건** | **메시지** |
|---|---|
| 두 갈래의 스택이 다름 | `the two branches of this if leave different stacks` |
| 한 바퀴가 스택을 바꿈 | `one turn of a loop must leave the stack as it found it` |
| 루프 밖의 `while` `until` `break` | `while, until and break belong inside a loop` |
| 닿지 않는 코드 | `this code cannot be reached: the code before it always leaves` |
| `case` 의 같은 값 | `this value is already in an earlier branch of the case` |
| 펼쳐지는 블록이 스택을 바꿈 | `this block must leave the stack as it found it` |
| 정의 밖의 `return` | `return belongs inside a definition` |
| 상수가 아닌 가지의 값 | `a case value is a literal or the name of a const` |
| 줄기가 아닌 것에 조합 낱말 | `only an array or a list is a stem (not a queue, a pool, a buffer or an index)` |
